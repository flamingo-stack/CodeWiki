Integration test suite for the CodeWiki ID-based clustering system, validating component ID map creation, normalization logic, and error handling across valid, invalid, and mixed input scenarios.

## Key Components

### `TestResults`
A simple test result tracker that accumulates pass/fail counts and prints a formatted summary with emoji status indicators.

### `MockNode`
A lightweight stub mimicking the real `Node` object interface (with `fqdn`, `name`, `file_path` attributes) used to build the `SAMPLE_COMPONENTS` fixture without requiring a live graph.

### `capture_log_warnings`
A decorator that temporarily attaches a `StringIO` handler to the `codewiki.src.be.cluster_modules` logger, returning both the function's result and any captured warning output — enabling assertions against log messages.

### Test Functions

| Function | What it validates |
|---|---|
| `test_component_id_map_creation` | `create_component_id_map` returns a correctly sized, sequentially-keyed dict mapping integer IDs → FQDNs |
| `test_valid_integer_ids` | Clean integer IDs normalize to FQDNs without warnings |
| `test_invalid_quoted_integers` | String-wrapped integers (`"0"`, `"1"`) are coerced via `int()` and accepted silently |
| `test_invalid_class_names` | Bare class name strings (`"AuthService"`) are rejected with a `Non-integer ID` warning and produce zero output components |
| `test_mixed_invalid_ids` | Mixed valid/invalid inputs partially normalize — valid IDs resolve, invalid ones are dropped with warnings |

## Usage Example

```bash
# Run from the repository root
python test_clustering_integration.py
```

```python
# Run a single test in isolation
from test_clustering_integration import TestResults, test_component_id_map_creation

results = TestResults()
test_component_id_map_creation(results)
results.print_summary()
```

The suite imports directly from [`codewiki/src/be/cluster_modules`](https://github.com/flamingo-stack/CodeWiki/blob/main/codewiki/src/be/cluster_modules) and requires no external test framework — `TestResults.print_summary()` returns `True` on a clean run, making it easy to integrate into CI as a plain Python script.
