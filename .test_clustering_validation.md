# test_clustering_validation.py

Standalone test script that validates the component-ID validation logic used during LLM-based module clustering (mirrors the checks in `cluster_modules.py` lines 338-369). It exercises the `json.loads()` parsing plus integer/range validation against a variety of valid and malformed inputs to ensure the LLM response validator correctly rejects bad data (e.g., quoted numbers, string class names, out-of-range or negative IDs, malformed JSON).

## Key Components

- **`TestResults`** — Accumulates pass/fail counts and failure details; provides `add_test()` to record outcomes and `print_summary()` to render a formatted report. Exposes a `success` property (`True` when zero failures).
- **`simulate_validation(response_content, max_id)`** — Reproduces the production validation flow: parses JSON safely, confirms the result is a `dict`, and checks that every component ID under each module's `"components"` key is an integer within `[0, max_id]`. Returns a `(success, module_tree)` tuple.
- **`test_cases`** — List of dictionaries defining scenarios (valid bare integers, quoted integers, string names, mixed types, out-of-range/negative IDs, malformed JSON, empty/missing `components`), each with expected pass/fail outcome.
- **`run_tests()`** — Iterates over `test_cases`, runs `simulate_validation`, compares actual vs. expected result, logs each test via `TestResults`, and prints the final summary.

## Usage Example

Run directly as a script:

```bash
python test_clustering_validation.py
```

The script exits with code `0` if all test cases pass, or `1` if any fail, making it suitable for CI pipelines:

```python
from test_clustering_validation import run_tests

if not run_tests():
    raise SystemExit("Clustering validation logic regressed")
```

Each test case prints detailed pass/fail logging plus a final summary table showing total tests, pass/fail counts, and success rate—useful for quickly diagnosing regressions in the LLM response validation logic before deploying changes to `cluster_modules.py`.
