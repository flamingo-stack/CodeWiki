Provides enhanced FQDN (Fully Qualified Domain Name) normalization utilities for resolving LLM-generated component IDs to their actual FQDNs in the `cluster_modules.py` pipeline, with multiple fallback matching strategies and improved debugging.

## Key Components

### `normalize_component_ids_enhanced(module_tree, components, short_to_fqdn)`
Main normalization function that iterates over modules and resolves each component ID using five progressive strategies:

| Strategy | Description |
|---|---|
| 1 – Exact FQDN | Direct lookup in `components` dict |
| 2 – Short ID map | Lookup via `short_to_fqdn` mapping |
| 3 – Strip `deps.` prefix | Handles LLM-added `deps.` prefixes, retries strategies 1–2 |
| 4 – Fuzzy name match | Matches on last path segment; resolves ambiguity via `_find_best_path_match` |
| 5 – Suffix path match | Tries matching last 2–4 dotted segments against known FQDNs |

Returns a `(total_normalized, total_failed)` tuple.

### `_find_best_path_match(llm_id, candidates)`
Scores candidate FQDNs by counting shared path segments and their relative positional similarity. Returns the top candidate only if it scores strictly higher than all others; returns `None` on ambiguity.

### `build_short_id_to_fqdn_map_enhanced(components)`
Builds an extended `short_id → FQDN` mapping that includes partial dotted paths (last 2–4 segments) in addition to bare short names, enabling matching of LLM outputs with partial directory prefixes. Logs and skips collisions.

## Usage Example

```python
from FQDN_NORMALIZATION_FIX import (
    normalize_component_ids_enhanced,
    build_short_id_to_fqdn_map_enhanced,
)

# Build the mapping once per analysis run
short_to_fqdn = build_short_id_to_fqdn_map_enhanced(components)

# Normalize LLM-returned component IDs in the module tree
normalized, failed = normalize_component_ids_enhanced(
    module_tree,
    components,
    short_to_fqdn,
)

print(f"Normalized: {normalized}, Failed: {failed}")
```

> **Integration note:** This module is intended to replace the normalization loop at lines 212–233 of [`cluster_modules.py`](https://github.com/flamingo-stack/CodeWiki/blob/main/cluster_modules.py). Import and call these functions in place of the existing loop.
