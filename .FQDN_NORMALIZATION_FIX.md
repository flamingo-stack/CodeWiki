This file is a **standalone reference/patch proposal** for `codewiki/src/be/cluster_modules.py`, addressing bugs in how LLM-generated component IDs are matched to actual Fully Qualified Domain Names (FQDNs) in the module tree. It is not currently imported or used anywhere in the codebase — it exists at the repository root temporarily for review and should eventually be merged into `cluster_modules.py` or removed.

The core problem it solves: LLMs generating module trees sometimes return component IDs that don't exactly match the parsed FQDNs (e.g., adding spurious `deps.` prefixes, using partial paths, or referencing only the last segment of a Java package path). This module implements a multi-strategy fallback resolver to reconcile these mismatches.

## Key Components

- **`normalize_component_ids_enhanced(module_tree, components, short_to_fqdn)`** — Main entry point. Iterates every module's component list and attempts to resolve each ID against the real `components` dict using five fallback strategies in order: exact match, short-ID lookup, `deps.` prefix stripping, fuzzy substring matching on the trailing name segment, and suffix-path matching. Returns `(total_normalized, total_failed)` counts and mutates `module_data['components']` in place with logging at each step.
- **`_find_best_path_match(llm_id, candidates)`** — Helper that disambiguates multiple fuzzy matches by scoring path-segment overlap and positional similarity, returning the clear winner or `None` if ambiguous.
- **`build_short_id_to_fqdn_map_enhanced(components)`** — Builds a lookup dictionary mapping both short component names and partial suffix paths (last 2–4 path segments) to their full FQDNs, to support partial-path matching from LLM output. (Note: the function body is truncated/incomplete in this file — it does not return the built `mapping`.)

## Usage Example

```python
from FQDN_NORMALIZATION_FIX import (
    normalize_component_ids_enhanced,
    build_short_id_to_fqdn_map_enhanced,
)

# components: Dict[str, Node] mapping FQDN -> parsed component node
short_to_fqdn = build_short_id_to_fqdn_map_enhanced(components)

# module_tree: Dict produced by the LLM clustering step
normalized, failed = normalize_component_ids_enhanced(
    module_tree, components, short_to_fqdn
)

print(f"Normalized {normalized} component IDs, {failed} could not be resolved")
```
