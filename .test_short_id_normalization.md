A test script that validates the short ID to FQDN (Fully Qualified Domain Name) normalization logic in `cluster_modules.py`, simulating scenarios where an LLM returns abbreviated component names instead of full identifiers.

## Key Components

- **`test_short_id_normalization()`** — Main test function that:
  - Builds a mock `components` dictionary using `Node` objects across Java and Python namespaces
  - Invokes `build_short_id_to_fqdn_map()` to generate the short ID → FQDN lookup table
  - Runs six normalization scenarios covering exact match, mapped short IDs, and missing components
  - Reports pass/fail counts and exits with a non-zero code on failure

## Usage Example

```bash
# Run directly from the repository root
python test_short_id_normalization.py
```

```python
# Core logic being exercised (from cluster_modules.py)
from codewiki.src.be.cluster_modules import build_short_id_to_fqdn_map
from codewiki.src.be.dependency_analyzer.models.core import Node

components = {
    "openframe-api.com.openframe.service.UserService": Node(
        id="openframe-api.com.openframe.service.UserService",
        name="UserService",
        short_id="UserService",
        namespace="openframe-api",
        component_type="class",
        file_path="/path/to/UserService.java",
        relative_path="com/openframe/service/UserService.java"
    )
}

short_to_fqdn = build_short_id_to_fqdn_map(components)
# Result: {"UserService": "openframe-api.com.openframe.service.UserService"}
```

## Test Cases Covered

| Input | Expected | Scenario |
|---|---|---|
| `AuthorizationServerConfig` | ✅ MAPPED | Short ID from Java component |
| `UserService` | ✅ MAPPED | Short ID from service component |
| `AuthManager` | ✅ MAPPED | Short ID from Python component |
| `LoginHandler` | ✅ MAPPED | Short ID from dependency component |
| `openframe-auth.com...AuthorizationServerConfig` | ✅ EXACT | Full FQDN already normalized |
| `NonExistentClass` | ❌ FAILED | Component does not exist |

## Notes

- Dependency components (`is_from_deps=True`) are included in the mapping
- The normalization priority is: exact FQDN match → short ID lookup → not found
