End-to-end smoke test that verifies CodeWiki's configuration pipeline works correctly using API keys from a local `.env.local` file, covering everything from key loading through LLM service instantiation.

## Key Components

| Function | Purpose |
|---|---|
| `test_env_loading()` | Loads and validates `OPENAI_API_KEY` and `ANTHROPIC_API_KEY` from `.env.local` |
| `test_config_manager_save()` | Persists a full three-tier model configuration (cluster / main / fallback) via `ConfigManager` |
| `test_config_manager_load()` | Reads the saved config back and asserts all three API keys are present |
| `test_backend_config_creation()` | Converts the CLI config into a `Config` backend object bound to the repo root |
| `test_llm_service_creation()` | Instantiates `create_cluster_model`, `create_main_model`, and `create_fallback_model` and confirms each holds its own API key |
| `main()` | Orchestrates all five tests in sequence; exits with a non-zero code on the first failure |

## Usage Example

Create `.env.local` in the repo root, then run the script directly:

```text
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
```

```bash
python test_local_config.py
```

Expected output on success:

```text
============================================================
CodeWiki Local Configuration Test
============================================================
✅ Loaded API keys from .env.local
✅ Configuration saved
✅ Configuration loaded successfully
✅ Backend Config created successfully
✅ Fallback model created with fallback_api_key

============================================================
🎉 SUCCESS: All tests passed!
============================================================
```

> **Note:** This is a developer utility script, not part of the production package. It is intended to be run once locally to confirm the environment is wired up before using `codewiki generate`. Configuration is persisted to `~/.codewiki/config.json`; API keys are stored in the system keychain.
