# test_clustering_local.py

Standalone local test script for validating CodeWiki's module clustering logic against a real sample repository, without running the full documentation generation workflow. It exercises `cluster_modules` with a small set of hand-crafted Java `Node` components to confirm the LLM correctly follows the clustering prompt format and returns a non-empty module tree.

## Key Components

- **`TestResults`**: Lightweight pass/fail accumulator class. Collects test outcomes via `add_test(name, passed, message)` and prints a formatted summary via `print_summary()`, returning `True` only if all tests passed.
- **`test_clustering(results)`**: Main test function that:
  - Reads the target repo path from the `CODEWIKI_TEST_REPO` environment variable.
  - Builds a `Config` object with cluster/main/fallback LLM model settings (using `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, or dedicated override env vars).
  - Constructs 4 sample `Node` components (`AuthController`, `AuthService`, `UserController`, `UserService`) representing Java classes in an `openframe-api` service.
  - Invokes `cluster_modules(...)` and validates that the returned `module_tree` is non-empty, printing detailed diagnostics either way.
- **`__main__` block**: Verifies an OpenAI/main API key is set before running, executes `test_clustering`, prints the summary, and exits with status code 0 (success) or 1 (failure).

## Usage Example

```bash
export OPENAI_API_KEY="your-key-here"
export CODEWIKI_TEST_REPO="/path/to/local/repo/containing/openframe-api"

python3 test_clustering_local.py
```

Programmatic use (e.g., in another script):

```python
from test_clustering_local import test_clustering, TestResults

results = TestResults()
success = test_clustering(results)
results.print_summary()
```

**Note:** The test repo must contain the specific hardcoded file paths (`openframe/services/openframe-api/.../AuthController.java`, etc.) for the sample components to resolve correctly—this script is tailored to the CodeWiki/OpenFrame monorepo structure.
