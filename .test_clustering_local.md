Local test script for validating the CodeWiki clustering module prompt fix, designed to run against a local repository without requiring the full workflow pipeline.

## Key Components

### `test_clustering()` → `bool`
Core test function that:
- Validates the local test repository exists
- Initializes a `Config` with OpenAI (`gpt-4o`) as primary and Anthropic (`claude-opus-4-5`) as fallback
- Constructs 4 sample `Node` objects representing Java controller/service classes
- Invokes `cluster_modules()` and validates the returned module tree is non-empty
- Returns `True` on success, `False` on empty results or exceptions

### Entry Point (`__main__`)
Checks for `OPENAI_API_KEY` or `MAIN_API_KEY` before running, exits with code `1` on failure.

## Usage Example

```bash
# Set required API key
export OPENAI_API_KEY='sk-...'

# Run the test
python3 test_clustering_local.py
```

```python
# What the script validates internally
module_tree = cluster_modules(
    leaf_nodes=list(components.keys()),
    components=components,
    config=config,
    current_module_tree={},
    current_module_name=None,
    current_module_path=[]
)

# Success: non-empty module tree
# Failure: empty dict → LLM did not follow prompt format
```

> **Note:** Update the `test_repo` variable inside `test_clustering()` to point to your local repository before running. The default path (`/Users/michaelassraf/Documents/GitHub/openframe-oss-tenant`) is developer-specific and will cause an early exit if not found.
