Primary service component that manages application lifecycle and request processing, leveraging helper utilities from the `deps` package for validation and data transformation.

## Key Components

### `MainService`
The core service class responsible for managing service state and processing requests.

| Method | Signature | Description |
|--------|-----------|-------------|
| `__init__` | `(name: str)` | Initializes the service with a name; sets `active = False` |
| `start` | `(config: dict) -> bool` | Validates config and activates the service |
| `process_request` | `(data: dict) -> dict` | Processes incoming data; raises `RuntimeError` if service is inactive |
| `stop` | `() -> None` | Deactivates the service |

### External Dependencies
- `deps.helper.validate_input` — Validates configuration before startup
- `deps.helper.process_data` — Transforms raw request data

## Usage Example

```python
from service import MainService

# Initialize and start the service
svc = MainService(name="my-service")

config = {"timeout": 30, "retries": 3}
started = svc.start(config)

if started:
    # Process a request
    response = svc.process_request({"key": "value"})
    print(response)
    # {
    #   "status": "success",
    #   "service": "my-service",
    #   "result": <processed_data>
    # }

    # Gracefully stop
    svc.stop()
else:
    print("Failed to start: invalid config")
```

## Notes

- `process_request` raises `RuntimeError` if called before `start()` or after `stop()`
- `start()` returns `False` (without activating) when `validate_input` rejects the config
