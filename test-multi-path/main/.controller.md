Handles HTTP-style API request routing by delegating business logic to `MainService` and tracking request counts.

## Key Components

- **`APIController`** — Main controller class that initializes a `MainService` instance and routes incoming requests to the appropriate handler.
  - `__init__()` — Sets up the `MainService` dependency and initializes a request counter.
  - `handle_request(endpoint, data)` — Routes requests based on endpoint path, returning processed results or health status.

## Supported Endpoints

| Endpoint | Behavior |
|---|---|
| `/process` | Delegates to `MainService.process_request()` |
| `/health` | Returns service health status and total request count |
| _(other)_ | Returns `{"error": "Unknown endpoint"}` |

## Usage Example

```python
from controller import APIController

controller = APIController()

# Process a request
response = controller.handle_request("/process", {"key": "value"})

# Check service health
health = controller.handle_request("/health", {})
# {"status": "healthy", "requests": 1}
```

## Notes

- Request count increments on **every** call to `handle_request`, including health checks.
- Unknown endpoints return an error dict rather than raising an exception — callers should check for the `"error"` key in the response.
- `MainService` is instantiated once at controller creation with the name `"api-service"`; it is not configurable via the constructor.
