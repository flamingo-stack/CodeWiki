## Overview

`test_multi_path.py` is a manual/integration test script for CodeWiki's multi-path analysis feature. It verifies that the `DependencyGraphBuilder` can correctly ingest, namespace, and cross-reference components discovered across multiple source directories (a primary repo path plus additional external paths) without ID collisions or missed dependencies.

## Key Components

- **`Colors`** — ANSI color code constants used to format terminal output (success, error, warning, headers).
- **`TestResults`** — Accumulator class that records pass/fail status per test via `add_test()` and prints a final tally with `print_summary()`, returning a process-friendly exit code (`0` = all passed, `1` = failures).
- **Print helpers** — `print_header()`, `print_success()`, `print_error()`, `print_warning()`, `print_info()` for consistent colored console output.
- **`create_test_config(repo_path, output_dir, additional_paths=None)`** — Builds a `Config` object pointing to test fixture directories (`main/`, `deps/`, `external/`), wiring in placeholder LLM model/API settings for the `DependencyGraphBuilder`.
- **Test functions** — Each exercises a specific scenario against `DependencyGraphBuilder.build_dependency_graph()`:
  - `test_single_path()` — Confirms backward compatibility when only one repo path is supplied.
  - `test_multiple_paths()` — Confirms components from `main/`, `deps/`, and `external/` are all discovered.
  - `test_component_namespacing()` — Confirms component IDs are unique across paths and encode path context to avoid collisions.
  - `test_cross_path_dependencies()` — Confirms dependency edges correctly link components across different source paths (e.g., `main/service.py` importing `deps/helper.py`).

## Usage Example

```bash
# Run the test suite directly from the tests directory
python3 test_multi_path.py
```

```python
# Programmatic invocation of an individual test
from test_multi_path import test_single_path, test_multiple_paths, TestResults

results = TestResults()
results.add_test("single_path", test_single_path())
results.add_test("multiple_paths", test_multiple_paths())

exit_code = results.print_summary()
```

Each test expects fixture directories (`main/`, `deps/`, `external/`) to exist alongside the script, containing sample Python files (e.g., `service.py`, `controller.py`, `helper.py`, `utils.py`, `plugin.py`) used to validate discovery and dependency resolution.
