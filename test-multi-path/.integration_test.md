End-to-end integration test runner for the CodeWiki multi-path analysis pipeline, validating the complete workflow from environment setup through dependency graph construction and namespace verification.

## Key Components

### `IntegrationTestRunner`
Main test orchestration class managing the full test lifecycle:

| Method | Description |
|---|---|
| `setup_test_environment()` | Creates a temporary 3-path directory structure (`main/`, `deps/`, `vendor/`) with sample Python files |
| `create_config()` | Instantiates a `Config` with `repo_path` pointing to `main/` and `additional_source_paths` for `deps/` and `vendor/` |
| `validate_paths()` | Asserts all configured paths exist on disk |
| `execute_dependency_parser()` | Runs `DependencyGraphBuilder.build_dependency_graph()` and collects components/leaf nodes |
| `verify_namespaces()` | Groups discovered components by top-level namespace and validates counts against expected values |
| `_assert(label, condition)` | Internal helper that appends results to `self.results["passed"]` or `self.results["failed"]` |

### Expected Test Topology

```text
test_dir/
├── main/       → service.py, api.py, models.py, controller.py, utils.py
├── deps/       → helper.py, validator.py, cache.py
└── vendor/     → logger.py, metrics.py
```

Cross-path import chain: `main/controller.py` → `main/api.py` → `deps/validator.py` → `vendor/logger.py`

### Expected Component Counts

| Namespace | Expected | Description |
|---|---|---|
| `main` | 7 | Classes + functions across all `main/` files |
| `deps` | 5 | Classes + functions across all `deps/` files |
| `vendor` | 2 | Classes only (`Logger`, `MetricsCollector`) |

## Usage Example

```python
runner = IntegrationTestRunner()

runner.setup_test_environment()   # Creates tmp dirs + sample files
runner.create_config()            # Builds multi-path Config
runner.validate_paths()           # Asserts all paths exist
runner.execute_dependency_parser()# Runs DependencyGraphBuilder
runner.verify_namespaces()        # Validates namespace prefixes + counts

print(runner.results["passed"])   # List of passed assertions
print(runner.results["failed"])   # List of failed assertions
print(runner.results["warnings"]) # Unexpected namespaces, etc.
```

Run directly from the repository root:

```bash
python tests/integration_test.py
```
