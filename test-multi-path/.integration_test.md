Concise documentation for `integration_test.py`:

---

An end-to-end integration test script that validates CodeWiki's multi-path dependency analysis pipeline by creating a temporary multi-directory project (`main/`, `deps/`, `vendor/`) with cross-path Python imports, then running it through the full `Config` → `DependencyGraphBuilder` pipeline and asserting on the resulting component graph and namespacing.

## Key Components

- **`TestResults`** — Accumulates named pass/fail test outcomes with optional detail messages; provides `add_test()`, `print_summary()` (formatted report with counts and warnings), and `all_passed()` for overall status.
- **`IntegrationTestRunner`** — Orchestrates the full test workflow via sequential steps:
  - `setup_test_environment()` — Creates a temp directory with `main/`, `deps/`, `vendor/` subdirectories.
  - `_create_main_files()`, `_create_deps_files()`, `_create_vendor_files()` — Populate each directory with sample Python modules exhibiting realistic cross-path imports (e.g., `main/service.py` imports from `deps.helper` and `vendor.logger`).
  - `create_config()` — Builds a `Config` object using `main/` as the repo root and `deps/`, `vendor/` as `additional_source_paths`.
  - `validate_paths()` — Confirms all configured source paths exist on disk.
  - `execute_dependency_parser()` — Instantiates `DependencyGraphBuilder`, verifies multi-path mode detection, and runs `build_dependency_graph()` to produce `components` and `leaf_nodes`.
  - `verify_namespaces()` — Groups discovered components by top-level namespace (derived from the dotted component ID prefix, e.g., `main`, `deps`, `vendor`) and prints a breakdown for manual/assertion-based inspection.

## Usage Example

```python
# Run as a standalone script
python integration_test.py

# Or drive it programmatically
from integration_test import IntegrationTestRunner

runner = IntegrationTestRunner()
runner.setup_test_environment()
runner.create_config()
runner.validate_paths()
runner.execute_dependency_parser()
runner.verify_namespaces()

runner.results.print_summary()
assert runner.results.all_passed()
```

**Note:** This script is intended to be executed directly from the `tests/` (or similar) directory adjacent to the `codewiki` package, since it inserts `CODEWIKI_ROOT` (`Path(__file__).parent.parent`) into `sys.path` to import `codewiki.src.config.Config` and `codewiki.src.be.dependency_analyzer.DependencyGraphBuilder`. Temporary directories are created via `tempfile.mkdtemp` and should be cleaned up (via `shutil`) after test completion.
