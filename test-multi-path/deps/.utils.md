Additional utility functions for string sanitization and simple hash calculation.

## Key Components

- **`sanitize_string(text: str) -> str`** — Strips non-alphanumeric characters from a string, preserving spaces.
- **`calculate_hash(data: str) -> int`** — Returns a simple 8-digit bounded hash of a string using Python's built-in `hash()`.

## Usage Example

```python
from utils import sanitize_string, calculate_hash

# Sanitize a string
clean = sanitize_string("Hello, World! #2024")
# clean → "Hello World 2024"

# Calculate a hash
hash_val = calculate_hash("my-data-key")
# hash_val → integer in range [0, 99_999_999]
```

> **Note:** `calculate_hash` uses Python's built-in `hash()`, which is non-deterministic across processes by default (due to hash randomization). Do not use this for persistent or cross-process key lookups.
