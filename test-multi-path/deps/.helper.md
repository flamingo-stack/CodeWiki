Helper utilities for validating, processing, and formatting dictionary-based data structures. Intended as a shared dependency module used alongside the main codebase.

## Key Components

| Function | Description |
|---|---|
| `validate_input(data)` | Checks that input is a `dict` containing required keys `"type"` and `"value"` |
| `process_data(data)` | Validates and transforms input, returning a new dict with uppercased type, stripped value, and a fixed timestamp |
| `format_output(data)` | Renders a processed data dict as a human-readable string |

## Usage Example

```python
from helper import validate_input, process_data, format_output

raw = {"type": "alert", "value": "  disk usage high  "}

# Validate before processing
if validate_input(raw):
    result = process_data(raw)
    print(result)
    # {
    #   "original": {"type": "alert", "value": "  disk usage high  "},
    #   "processed_type": "ALERT",
    #   "processed_value": "disk usage high",
    #   "timestamp": "2024-01-01T00:00:00Z"
    # }

    print(format_output(result))
    # [ALERT] disk usage high
```

## Notes

- `process_data` raises `ValueError` if validation fails — always validate first or handle the exception.
- `format_output` uses `.get()` with safe defaults (`"UNKNOWN"` / empty string), so it won't raise on partial data.
- The `timestamp` field is currently hardcoded; replace with `datetime.utcnow().isoformat()` for production use.
