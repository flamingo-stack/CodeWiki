Provides a singleton `FileManager` utility class for common file I/O operations, including directory creation and reading/writing JSON and plain text files.

## Key Components

### `FileManager` (class)

A static-method-only class for file system operations:

| Method | Description |
|---|---|
| `ensure_directory(path)` | Creates a directory and all parent directories (equivalent to `mkdir -p`) |
| `save_json(data, filepath)` | Serializes any JSON-compatible value to a file with 4-space indentation |
| `load_json(filepath)` | Reads and parses a JSON file; returns `None` if the file does not exist |
| `save_text(content, filepath)` | Writes a string to a file |
| `load_text(filepath)` | Reads and returns the full contents of a text file |

### `file_manager` (instance)

A module-level singleton instance of `FileManager` for convenient import and use.

## Usage Example

```python
from utils import file_manager

# Create nested directories
file_manager.ensure_directory("/docs/Backend/Auth/JWT")

# Save and load JSON
file_manager.save_json({"key": "value"}, "/docs/config.json")
config = file_manager.load_json("/docs/config.json")  # {"key": "value"}
missing = file_manager.load_json("/does/not/exist.json")  # None

# Save and load plain text
file_manager.save_text("# Hello World", "/docs/README.md")
content = file_manager.load_text("/docs/README.md")  # "# Hello World"
```
