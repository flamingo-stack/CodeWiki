Provides file I/O utility helpers for reading and writing JSON and text files, along with directory management, used across the CodeWiki backend and web application.

## Key Components

- **`FileManager`** - Static utility class encapsulating common file operations:
  - `ensure_directory(path)` - Recursively creates a directory (and parent directories) if it doesn't already exist.
  - `save_json(data, filepath)` - Serializes a Python object to JSON and writes it to a file with 4-space indentation.
  - `load_json(filepath)` - Reads and parses a JSON file, returning `None` if the file doesn't exist.
  - `save_text(content, filepath)` - Writes plain text content to a file.
  - `load_text(filepath)` - Reads and returns plain text content from a file.
- **`file_manager`** - Pre-instantiated module-level instance of `FileManager` for convenient import and use.

## Usage Example

```python
from utils import file_manager, FileManager

# Ensure nested directory structure exists
FileManager.ensure_directory("/docs/Backend/Auth/JWT")

# Save and load JSON data
file_manager.save_json({"key": "value", "count": 42}, "/docs/data.json")
data = file_manager.load_json("/docs/data.json")  # Returns dict, or None if missing

# Save and load plain text
file_manager.save_text("Hello, CodeWiki!", "/docs/notes.txt")
content = file_manager.load_text("/docs/notes.txt")
```

**Notes:**
- All methods are `@staticmethod`, so they can be called directly on the class (`FileManager.save_json(...)`) or via the shared `file_manager` instance.
- `load_json` gracefully returns `None` for missing files instead of raising an exception, simplifying optional-config-loading patterns.
- File operations use standard text mode (`'w'`/`'r'`) and do not currently handle encoding overrides or binary content.
