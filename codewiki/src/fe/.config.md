Configuration settings and constants for the CodeWiki web application, centralizing directory paths, queue parameters, cache policies, server defaults, and Git clone behavior.

## Key Components

| Name | Type | Description |
|---|---|---|
| `WebAppConfig` | Class | Central configuration container with class-level constants and utility methods |
| `ensure_directories()` | Classmethod | Creates `CACHE_DIR`, `TEMP_DIR`, and `OUTPUT_DIR` if they don't exist |
| `get_absolute_path()` | Classmethod | Resolves a relative path string to its absolute path |

### Configuration Constants

| Constant | Default | Description |
|---|---|---|
| `CACHE_DIR` | `./output/cache` | Cached documentation output |
| `TEMP_DIR` | `./output/temp` | Temporary processing files |
| `OUTPUT_DIR` | `./output` | Base output directory |
| `QUEUE_SIZE` | `100` | Maximum job queue capacity |
| `CACHE_EXPIRY_DAYS` | `365` | Cache TTL in days |
| `JOB_CLEANUP_HOURS` | `24000` | Hours before stale jobs are purged |
| `RETRY_COOLDOWN_MINUTES` | `3` | Delay between job retries |
| `DEFAULT_HOST` | `127.0.0.1` | Server bind address |
| `DEFAULT_PORT` | `8000` | Server listen port |
| `CLONE_TIMEOUT` | `300` | Git clone timeout in seconds |
| `CLONE_DEPTH` | `1` | Shallow clone depth |

## Usage Example

```python
from config import WebAppConfig

# Initialize required directories at startup
WebAppConfig.ensure_directories()

# Resolve a relative path to absolute
abs_path = WebAppConfig.get_absolute_path(WebAppConfig.CACHE_DIR)
print(abs_path)  # e.g. /app/output/cache

# Access constants directly
print(f"Serving on {WebAppConfig.DEFAULT_HOST}:{WebAppConfig.DEFAULT_PORT}")
print(f"Cache expires after {WebAppConfig.CACHE_EXPIRY_DAYS} days")
```

> **Note:** All paths are relative to the working directory at runtime. Call `ensure_directories()` once during application startup to avoid missing-directory errors during cache writes or job processing.
