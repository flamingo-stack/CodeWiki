Manages a persistent cache for documentation generation results, storing and retrieving previously generated docs by repository URL to avoid redundant processing.

## Key Components

- **`CacheManager`** — Main class that handles all cache operations with configurable directory and expiry settings
- **`load_cache_index()`** — Deserializes the `cache_index.json` file from disk into `CacheEntry` model instances
- **`save_cache_index()`** — Serializes the in-memory cache index back to `cache_index.json` on disk
- **`get_repo_hash(repo_url)`** — Generates a 16-character SHA-256 hash used as the cache key for a given repository URL
- **`get_cached_docs(repo_url)`** — Returns the cached docs path if the entry exists and has not expired; auto-removes stale entries
- **`add_to_cache(repo_url, docs_path)`** — Creates a new `CacheEntry` and persists it to the index
- **`remove_from_cache(repo_url)`** — Deletes a single entry by repo URL hash and saves the updated index
- **`cleanup_expired_cache()`** — Batch-removes all entries older than the configured expiry threshold

## Usage Example

```python
from cache_manager import CacheManager

# Initialize with defaults from WebAppConfig
cache = CacheManager()

repo_url = "https://github.com/flamingo-stack/CodeWiki"
docs_path = "/generated/docs/flamingo-stack_codewiki"

# Add generated docs to cache
cache.add_to_cache(repo_url, docs_path)

# Retrieve cached docs (returns None if expired or missing)
cached = cache.get_cached_docs(repo_url)
if cached:
    print(f"Using cached docs at: {cached}")
else:
    # Trigger generation...
    pass

# Periodic cleanup of stale entries
cache.cleanup_expired_cache()
```

> **Note:** Cache expiry and storage directory are configured via `WebAppConfig.CACHE_EXPIRY_DAYS` and `WebAppConfig.CACHE_DIR`, but can be overridden at instantiation time.
