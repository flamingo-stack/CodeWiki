Manages a disk-backed cache of generated documentation, keyed by a hash of the repository URL. It persists a JSON index of cache entries (with creation and last-accessed timestamps) and handles expiry-based invalidation.

## Key Components

- **`CacheManager`** — main class managing the cache lifecycle.
  - `__init__(cache_dir=None, cache_expiry_days=None)` — sets up the cache directory (falling back to `WebAppConfig` defaults) and loads the existing index.
  - `load_cache_index()` — reads `cache_index.json` from disk into memory as `CacheEntry` objects; if the file is corrupted, backs it up with a timestamped filename and resets the in-memory index.
  - `save_cache_index()` — serializes the in-memory index back to `cache_index.json`.
  - `get_repo_hash(repo_url)` — returns a truncated SHA-256 hash of the repo URL, used as the cache key.
  - `get_cached_docs(repo_url)` — returns the cached docs path if a valid (non-expired) entry exists, updating `last_accessed`; otherwise removes expired entries and returns `None`.
  - `add_to_cache(repo_url, docs_path)` — inserts or overwrites a cache entry with current timestamps.
  - `remove_from_cache(repo_url)` — deletes a specific entry from the index.
  - `cleanup_expired_cache()` — sweeps and removes all entries older than the configured expiry window.

## Usage Example

```python
from cache_manager import CacheManager

# Initialize (uses WebAppConfig defaults if args omitted)
cache = CacheManager(cache_dir="./cache", cache_expiry_days=7)

repo_url = "https://github.com/flamingo-stack/CodeWiki"

# Check for existing cached docs
docs_path = cache.get_cached_docs(repo_url)

if docs_path is None:
    # Simulate generating docs, then cache the result
    generated_path = "/tmp/generated_docs/CodeWiki"
    cache.add_to_cache(repo_url, generated_path)
    docs_path = generated_path

print(f"Docs available at: {docs_path}")

# Periodic maintenance
cache.cleanup_expired_cache()
```

**Notes:**
- Depends on `CacheEntry` (`.models`), `WebAppConfig` (`.config`), and `file_manager` (`codewiki.src.utils`) for JSON persistence.
- Cache validity is determined by `created_at`, not `last_accessed`, so entries expire on a fixed schedule regardless of access frequency.
