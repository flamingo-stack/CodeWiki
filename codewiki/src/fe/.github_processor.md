Utilities for validating, parsing, and cloning GitHub repositories. Provides a clean interface for extracting repository metadata from URLs and performing `git clone` operations with optional commit checkout support.

## Key Components

### `GitHubRepoProcessor`

Static utility class with three methods:

| Method | Description |
|---|---|
| `is_valid_github_url(url)` | Validates that a URL points to a GitHub repo (`github.com/{owner}/{repo}`) |
| `get_repo_info(url)` | Parses a GitHub URL and returns owner, repo name, full name, and clone URL |
| `clone_repository(clone_url, target_dir, commit_id)` | Clones a repo; uses shallow clone by default, full clone when a specific commit is needed |

## Usage Example

```python
from github_processor import GitHubRepoProcessor

url = "https://github.com/flamingo-stack/CodeWiki"

# Validate URL
if GitHubRepoProcessor.is_valid_github_url(url):

    # Extract repo metadata
    info = GitHubRepoProcessor.get_repo_info(url)
    # {
    #   'owner': 'flamingo-stack',
    #   'repo': 'CodeWiki',
    #   'full_name': 'flamingo-stack/CodeWiki',
    #   'clone_url': 'https://github.com/flamingo-stack/CodeWiki.git'
    # }

    # Shallow clone (default)
    GitHubRepoProcessor.clone_repository(info['clone_url'], '/tmp/codewiki')

    # Clone and checkout a specific commit
    GitHubRepoProcessor.clone_repository(
        info['clone_url'],
        '/tmp/codewiki-pinned',
        commit_id='a1b2c3d'
    )
```

## Notes

- Shallow clones use `CLONE_DEPTH` and `CLONE_TIMEOUT` from `WebAppConfig`
- Full clones (triggered by `commit_id`) bypass depth limits to ensure the target commit is accessible
- Returns `False` on any clone or checkout failure; errors are printed to stdout
- `.git` suffix is stripped automatically from repo names parsed via `get_repo_info`
