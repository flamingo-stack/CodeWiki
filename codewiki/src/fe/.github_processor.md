Provides utilities for validating GitHub repository URLs, extracting repository metadata, and cloning repositories to a local target directory (with optional checkout of a specific commit).

## Key Components

- **`GitHubRepoProcessor`** — Static-method utility class for GitHub repo operations:
  - **`is_valid_github_url(url)`** — Validates that a URL points to `github.com` (or `www.github.com`) and contains at least an `owner/repo` path.
  - **`get_repo_info(url)`** — Parses a GitHub URL and returns a dict with `owner`, `repo`, `full_name`, and `clone_url` (strips trailing `.git` from the repo name).
  - **`clone_repository(clone_url, target_dir, commit_id=None)`** — Clones a repository into `target_dir`. Performs a shallow clone (using `WebAppConfig.CLONE_DEPTH`) by default, or a full clone followed by `git checkout` when a specific `commit_id` is provided. Cleans up the target directory on failure and returns a boolean success status.

## Usage Example

```python
from github_processor import GitHubRepoProcessor

url = "https://github.com/flamingo-stack/CodeWiki"

if GitHubRepoProcessor.is_valid_github_url(url):
    info = GitHubRepoProcessor.get_repo_info(url)
    print(info)
    # {'owner': 'flamingo-stack', 'repo': 'CodeWiki',
    #  'full_name': 'flamingo-stack/CodeWiki',
    #  'clone_url': 'https://github.com/flamingo-stack/CodeWiki.git'}

    success = GitHubRepoProcessor.clone_repository(
        clone_url=info['clone_url'],
        target_dir="/tmp/repos/CodeWiki",
        commit_id=None  # or a specific commit SHA
    )

    if success:
        print("Repository cloned successfully.")
    else:
        print("Failed to clone repository.")
```

**Notes:**
- Requires `git` to be installed and available on the system `PATH`.
- Relies on `WebAppConfig.CLONE_TIMEOUT` and `WebAppConfig.CLONE_DEPTH` for clone behavior configuration.
- Automatically removes partially-cloned directories on failure to avoid leaving corrupted state.
