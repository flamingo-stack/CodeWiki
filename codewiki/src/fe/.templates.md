Defines and exports the two HTML Jinja2 templates used by the CodeWiki Flask web application: the main submission interface (`WEB_INTERFACE_TEMPLATE`) and the documentation viewer (`DOCS_VIEW_TEMPLATE`).

## Key Components

| Constant | Description |
|---|---|
| `WEB_INTERFACE_TEMPLATE` | Jinja2 HTML template for the home page — includes the repo URL form, optional commit hash input, recent jobs list with status badges, and a manual refresh button |
| `DOCS_VIEW_TEMPLATE` | Jinja2 HTML template for rendered documentation pages — includes a fixed sidebar nav, Mermaid.js v11.9.0 for diagram rendering, and a main content area |

## Usage Example

```python
from flask import render_template_string
from templates import WEB_INTERFACE_TEMPLATE, DOCS_VIEW_TEMPLATE

# Render the submission form
@app.route("/")
def index():
    return render_template_string(
        WEB_INTERFACE_TEMPLATE,
        message="Job queued!",
        message_type="success",
        repo_url="",
        commit_id="",
        recent_jobs=[
            {
                "job_id": "abc123",
                "repo_url": "https://github.com/owner/repo",
                "status": "completed",
                "progress": "Done",
                "main_model": "gpt-4o",
            }
        ],
    )

# Render a documentation page
@app.route("/docs/<job_id>")
def view_docs(job_id):
    return render_template_string(
        DOCS_VIEW_TEMPLATE,
        title="My Repo Docs",
        # additional context vars...
    )
```

**Template variables — `WEB_INTERFACE_TEMPLATE`:**

| Variable | Type | Purpose |
|---|---|---|
| `message` | `str` | Flash message text |
| `message_type` | `str` | `"success"` or `"error"` |
| `repo_url` | `str` | Pre-fills the URL input |
| `commit_id` | `str` | Pre-fills the commit input |
| `recent_jobs` | `list[dict]` | Jobs with `job_id`, `status`, `progress`, `main_model` |

**Template variables — `DOCS_VIEW_TEMPLATE`:**

| Variable | Type | Purpose |
|---|---|---|
| `title` | `str` | Browser tab title |

> **Note:** `DOCS_VIEW_TEMPLATE` includes Mermaid.js from jsDelivr CDN. Ensure CSP headers allow `cdn.jsdelivr.net` in production.
