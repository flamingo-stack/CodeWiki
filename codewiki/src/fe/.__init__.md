Initializes and exports the CodeWiki frontend module, providing the web interface components for the documentation generation service.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `app` | FastAPI app | The main web application instance |
| `main` | Function | Entry point for running the web server |
| `JobStatus` | Enum/Model | Represents the status of a documentation job |
| `JobStatusResponse` | Model | API response schema for job status queries |
| `RepositorySubmission` | Model | Request schema for submitting a GitHub repository |
| `CacheEntry` | Model | Data model for cached documentation entries |
| `CacheManager` | Class | Handles caching of generated documentation |
| `BackgroundWorker` | Class | Manages async background documentation generation jobs |
| `GitHubRepoProcessor` | Class | Processes and fetches source files from GitHub repositories |
| `WebRoutes` | Class | Registers and organizes HTTP route handlers |

## Usage Example

```python
from frontend import app, main, GitHubRepoProcessor, CacheManager

# Run the web application
if __name__ == "__main__":
    main()

# Or use individual components directly
processor = GitHubRepoProcessor(repo_url="https://github.com/flamingo-stack/CodeWiki")
cache = CacheManager()

# Submit a repository for documentation generation
from frontend import RepositorySubmission, JobStatus

submission = RepositorySubmission(repo_url="https://github.com/flamingo-stack/CodeWiki")
```
