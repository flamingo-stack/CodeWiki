Jinja2 template rendering utilities for FastAPI applications, providing string-based template loading and HTML component rendering functions for navigation and job list UI elements.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `StringTemplateLoader` | Class | Custom Jinja2 `BaseLoader` that renders templates from raw strings rather than files |
| `render_template` | Function | Core renderer — wraps a Jinja2 environment around a string template and injects context variables |
| `render_navigation` | Function | Generates sidebar navigation HTML from a nested module tree dict, with active-page highlighting |
| `render_job_list` | Function | Generates a job status list HTML fragment from a list of job objects |

## Usage Example

```python
from template_utils import render_template, render_navigation, render_job_list

# Render an arbitrary string template
html = render_template(
    template="<h1>Hello, {{ name }}!</h1>",
    context={"name": "World"}
)

# Render navigation from a module tree
module_tree = {
    "api_docs": {
        "components": ["routes"],
        "children": {
            "auth": {},
            "users": {}
        }
    }
}
nav_html = render_navigation(module_tree, current_page="auth.md")

# Render a job status list
jobs = [
    type("Job", (), {
        "repo_url": "https://github.com/flamingo-stack/CodeWiki",
        "status": "completed",
        "progress": "100%",
        "job_id": "abc123",
        "docs_path": "/docs/abc123"
    })()
]
job_html = render_job_list(jobs)
```

## Notes

- Autoescape is enabled for `html` and `xml` contexts, preventing XSS from user-supplied data.
- `trim_blocks` and `lstrip_blocks` are set to `True` to suppress extra whitespace in rendered output.
- Both `render_navigation` and `render_job_list` return an empty string `""` when passed empty inputs, making them safe for conditional rendering.
