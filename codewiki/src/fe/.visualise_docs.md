# visualise_docs.py

A lightweight FastAPI-based documentation server that renders markdown files from a specified documentation folder into styled HTML pages, with support for hierarchical navigation and Mermaid diagram rendering.

This module serves a documentation folder structure containing an `overview.md` entry point, a `module_tree.json` navigation hierarchy, and various module-specific `.md` files. It converts markdown to HTML on the fly, handles Mermaid diagram code blocks specially, and prevents directory traversal attacks when serving arbitrary markdown files.

## Key Components

- **`app`** – The FastAPI application instance exposing the documentation routes.
- **`initialize_globals()`** – Lazily initializes `DOCS_FOLDER` and `MODULE_TREE` from the `DOCS_FOLDER` environment variable (used to support uvicorn's reload mode).
- **`load_module_tree(docs_folder)`** – Loads and parses `module_tree.json` for sidebar navigation.
- **`markdown_to_html(content)`** – Renders markdown to HTML via `MarkdownIt`, post-processing `language-mermaid` code blocks into `<div class="mermaid">` elements for client-side diagram rendering.
- **`get_file_title(file_path)`** – Extracts a page title from the first `# Heading` line of a markdown file, falling back to a formatted filename.
- **`index()`** (`GET /`) – Serves `overview.md` as the landing page.
- **`serve_doc(filename)`** (`GET /{filename:path}`) – Serves any other `.md` file within the docs folder, with path traversal protection restricting access to files inside `DOCS_FOLDER`.
- **`main()`** – CLI entry point parsing `--docs-folder`, `--port`, `--host`, and `--debug` arguments, then launches the server via `uvicorn`.

## Usage Example

Run the server from the command line:

```bash
python -m codewiki.visualise_docs --docs-folder ./output/my_project_docs --port 8080
```

Then open `http://127.0.0.1:8080` in a browser to view `overview.md`, or navigate to any indexed module, e.g. `http://127.0.0.1:8080/module_name.md`.

Programmatic use with uvicorn directly:

```python
import os
os.environ["DOCS_FOLDER"] = "/path/to/docs"

import uvicorn
uvicorn.run("codewiki.visualise_docs:app", host="127.0.0.1", port=8000, reload=True)
```

**Expected docs folder layout:**

```text
docs/
├── overview.md
├── module_tree.json
├── module_a.md
└── module_b.md
```

## Notes

- Only `.md` files are servable; all other paths return `404`.
- File access is resolved and validated against the docs folder root to prevent directory traversal (`403` on violation).
- Static assets are mounted at `/static` from the current working directory.
