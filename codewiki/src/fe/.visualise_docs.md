A FastAPI-based documentation server that serves markdown files from a structured docs folder, rendering them as HTML with Mermaid diagram support and hierarchical navigation.

## Key Components

### FastAPI Application (`app`)
The core web server instance configured to serve documentation via HTTP endpoints.

### Global State
- `DOCS_FOLDER` — Path to the documentation root directory
- `MODULE_TREE` — Loaded hierarchy from `module_tree.json`, used to build navigation

### Functions

| Function | Description |
|---|---|
| `initialize_globals()` | Lazily loads `DOCS_FOLDER` and `MODULE_TREE` from the `DOCS_FOLDER` env var |
| `load_module_tree(docs_folder)` | Parses `module_tree.json` into a Python dict for navigation rendering |
| `markdown_to_html(content)` | Converts markdown to HTML; post-processes Mermaid code blocks into `<div class="mermaid">` elements |
| `get_file_title(file_path)` | Extracts the first `# H1` heading from a `.md` file, falling back to a formatted filename |
| `main()` | CLI entry point; validates args and launches `uvicorn` |

### Routes

| Route | Description |
|---|---|
| `GET /` | Serves `overview.md` as the landing page |
| `GET /{filename:path}` | Serves any `.md` file; includes directory traversal protection |

## Usage Example

```bash
# Start the server
python visualise_docs.py --docs-folder ./docs --port 8080 --host 0.0.0.0

# Optional flags
python visualise_docs.py --docs-folder ./docs --debug  # Enable hot reload + debug logging
```

```text
Expected docs folder layout:
docs/
├── overview.md          ← Landing page (required)
├── module_tree.json     ← Navigation tree (optional but recommended)
├── authentication.md
└── api_reference.md
```

The `DOCS_FOLDER` environment variable can be set as an alternative to `--docs-folder`, which also enables the server to pick up configuration on uvicorn reload.
