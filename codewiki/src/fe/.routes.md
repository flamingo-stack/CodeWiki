## Purpose

Defines the `WebRoutes` class, which implements FastAPI HTTP handlers for the CodeWiki web application, including the submission form, job status polling, and serving of generated documentation pages.

## Key Components

- **`WebRoutes`** — Class encapsulating all route handlers; constructed with a `BackgroundWorker` and `CacheManager`.
- **`index_get`** — Renders the main submission page with recent job history.
- **`index_post`** — Validates a submitted GitHub URL, checks for cache hits, duplicate/recent-failed jobs, or enqueues a new documentation-generation job.
- **`get_job_status`** — JSON API endpoint returning a `JobStatusResponse` for a given `job_id`.
- **`view_docs`** — Redirects to the static documentation viewer once a job completes.
- **`serve_generated_docs`** — Resolves and renders a specific markdown doc file (converted to HTML) for a job, falling back to cache lookup if no in-memory job status exists; includes path-traversal protection.
- **`_normalize_github_url`** — Internal helper to standardize a GitHub repo URL to `https://github.com/{full_name}` form using `GitHubRepoProcessor`.

## Usage Example

```python
from fastapi import FastAPI
from codewiki.webapp.routes import WebRoutes
from codewiki.webapp.background_worker import BackgroundWorker
from codewiki.webapp.cache_manager import CacheManager

app = FastAPI()
worker = BackgroundWorker()
cache = CacheManager()
routes = WebRoutes(background_worker=worker, cache_manager=cache)

app.add_api_route("/", routes.index_get, methods=["GET"])
app.add_api_route("/", routes.index_post, methods=["POST"])
app.add_api_route("/api/jobs/{job_id}", routes.get_job_status, methods=["GET"])
app.add_api_route("/docs/{job_id}", routes.view_docs, methods=["GET"])
app.add_api_route(
    "/static-docs/{job_id}/{filename}",
    routes.serve_generated_docs,
    methods=["GET"],
)
```

**Notes:**
- Jobs are keyed by a deterministic `job_id` derived from the repo's `owner/name`, enabling cache reuse and duplicate-submission detection.
- Recently failed jobs are blocked from resubmission for `WebAppConfig.RETRY_COOLDOWN_MINUTES`.
- `serve_generated_docs` guards against path traversal by resolving the requested file path and verifying it stays within the docs directory.
