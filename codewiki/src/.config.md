## config.py

Defines the central `Config` dataclass that drives the CodeWiki documentation-generation pipeline, encapsulating repository paths, output directories, per-provider LLM settings (models, API keys, base URLs, temperatures, token limits), and agent instruction customization (include/exclude patterns, focus modules, doc type, custom instructions). It also supports multi-path source analysis and safe serialization that excludes runtime secrets.

## Key Components

- **`Config`** — Core dataclass holding repo/output paths, per-provider (`cluster`, `main`, `fallback`) model/API/temperature/token settings, `agent_instructions`, and optional `additional_source_paths` for multi-path mode.
- **`Config.to_dict()` / `Config.from_dict()`** — Serialize/deserialize a `Config`, excluding API key fields (`cluster_api_key`, `main_api_key`, `fallback_api_key`) by default via `_RUNTIME_ONLY_SECRET_FIELDS` to prevent leaking secrets into logs/caches.
- **Properties** — `include_patterns`, `exclude_patterns`, `focus_modules`, `doc_type`, `custom_instructions`: convenience accessors reading from `agent_instructions`.
- **`all_source_paths`** — Returns absolute paths for `repo_path` plus any `additional_source_paths`.
- **`validate_source_paths()`** — Verifies primary and additional paths exist, are directories, and are readable; raises `ValueError`/`OSError` otherwise.
- **`is_multi_path_mode()`** — Returns whether multiple source paths are configured.
- **`get_prompt_addition()`** — Builds LLM prompt text based on `doc_type` and other agent instructions.
- **Constants** — `OUTPUT_BASE_DIR`, `DEPENDENCY_GRAPHS_DIR`, `DOCS_DIR`, `MAX_DEPTH`, default token limits (`DEFAULT_MAX_TOKENS`, `DEFAULT_MAX_TOKEN_PER_MODULE`, `DEFAULT_MAX_TOKEN_PER_LEAF_MODULE`), and filenames (`MODULE_TREE_FILENAME`, `OVERVIEW_FILENAME`).
- **`set_cli_context()` / `is_cli_context()`** — Track whether the module is running in CLI vs. web-app context, affecting how LLM credentials are loaded.

## Usage Example

```python
from codewiki.src.be.config import Config

config = Config(
    repo_path="/path/to/repo",
    output_dir="output",
    dependency_graph_dir="output/dependency_graphs",
    docs_dir="output/docs",
    max_depth=2,
    main_model="claude-sonnet-4",
    cluster_model="claude-sonnet-4",
    fallback_model="gpt-4o",
    cluster_api_key="sk-...",
    main_api_key="sk-...",
    fallback_api_key="sk-...",
)

# Validate all configured source paths exist and are readable
config.validate_source_paths()

# Check multi-path mode
if config.is_multi_path_mode():
    print("Analyzing paths:", config.all_source_paths)

# Serialize safely (no secrets included)
safe_dict = config.to_dict()

# Get doc-type-specific prompt guidance
extra_prompt = config.get_prompt_addition()
```
