Defines and manages all configuration settings for CodeWiki, including directory paths, LLM provider parameters, and runtime context flags. It exposes a central `Config` dataclass used throughout the codebase, along with CLI argument parsing and environment variable loading.

## Key Components

- **Module-level constants** — Default paths (`OUTPUT_BASE_DIR`, `DOCS_DIR`, etc.), token limits (`DEFAULT_MAX_TOKENS`, `DEFAULT_MAX_TOKEN_PER_MODULE`), and model names read from environment variables (`MAIN_MODEL`, `CLUSTER_MODEL`, `LLM_BASE_URL`).
- **CLI context helpers** — `set_cli_context()` and `is_cli_context()` toggle a global flag that switches between CLI (file-based secrets) and web app (env var) modes.
- **`Config` dataclass** — Central configuration object holding repo paths, per-provider LLM settings (model name, API key, base URL, API version, token limits, temperature), and optional agent instructions.
  - **Properties**: `include_patterns`, `exclude_patterns`, `focus_modules`, `doc_type`, `custom_instructions`, `all_source_paths` — derived from `agent_instructions`.
  - **`validate_source_paths()`** — Asserts all configured paths exist, are directories, and are readable.
  - **`is_multi_path_mode()`** — Returns `True` when `additional_source_paths` is non-empty.
  - **`get_prompt_addition()`** — Assembles an LLM prompt string from `doc_type`, `focus_modules`, and `custom_instructions` (curly braces are escaped via `escape_format_braces`).
  - **`from_args(cls, args)`** — Factory classmethod that builds a `Config` from an `argparse.Namespace`, reading required env vars (`FALLBACK_MODEL`, `CLUSTER_API_KEY`, `MAIN_API_KEY`, `FALLBACK_API_KEY`).

## Usage Example

```python
import argparse
from codewiki.src.be.config import Config, set_cli_context

# Enable CLI mode (reads keys from ~/.codewiki/config.json + keyring)
set_cli_context(True)

# Build config from CLI args
parser = argparse.ArgumentParser()
parser.add_argument("repo_path")
args = parser.parse_args(["./my-repo"])

config = Config.from_args(args)

# Inspect resolved paths
print(config.all_source_paths)   # ['/abs/path/to/my-repo']
print(config.is_multi_path_mode())  # False

# Validate all paths before processing
config.validate_source_paths()

# Generate extra LLM prompt text from agent instructions
config.agent_instructions = {
    "doc_type": "api",
    "focus_modules": ["auth", "payments"],
    "custom_instructions": "Include curl examples for every endpoint.",
}
print(config.get_prompt_addition())
```
