## cluster_modules.py

This module implements the LLM-driven clustering pipeline that groups leaf-level code components (classes, functions, files) into higher-level "modules" for CodeWiki's documentation generation. It uses an integer ID mapping scheme to keep LLM prompts compact, then normalizes returned IDs back to fully-qualified domain names (FQDNs), recursively clustering sub-modules until each fits within the configured token budget.

## Key Components

- **`extract_module_hint(fqdn)`** — Derives a human-readable module name from an FQDN (e.g., `api-service`, `auth`) using pattern matching on service/API naming conventions and file path segments.
- **`extract_package_hint(fqdn)`** — Derives a package/category hint (e.g., `controller`, `service`, `model`) from an FQDN by matching common architectural layer names.
- **`create_component_id_map(components)`** — Builds bidirectional mappings: `id_to_fqdn` (integer → FQDN) and `id_descriptions` (integer string → readable `"ClassName (module, package)"` label), enabling compact LLM prompts.
- **`format_potential_core_components(leaf_nodes, components)`** — Formats leaf components into ID-based text blocks (with and without source code) grouped by file, filtering out invalid/missing leaf nodes with detailed warnings. Returns the formatted strings plus the ID mappings for later normalization.
- **`normalize_component_id_list(component_ids, id_to_fqdn, components, context)`** — Resolves a list of LLM-returned component IDs back to FQDNs, tolerating both integer IDs and verbatim FQDN strings the LLM may echo. Returns resolved FQDNs plus counts of normalized/failed entries.
- **`normalize_component_ids_by_lookup(module_tree, id_to_fqdn)`** — Recursively walks an LLM clustering response tree, replacing all component IDs with FQDNs via direct dictionary lookup (a simplified replacement for legacy fuzzy-matching logic).

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.cluster_modules import (
    create_component_id_map,
    format_potential_core_components,
    normalize_component_id_list,
)

# components: Dict[str, Node] keyed by FQDN
id_to_fqdn, id_descriptions = create_component_id_map(components)

prompt_text, prompt_text_with_code, id_to_fqdn, id_descriptions = (
    format_potential_core_components(leaf_nodes=list(components.keys()), components=components)
)

# ... send prompt_text to LLM, receive component_ids in response ...
resolved_fqdns, num_normalized, num_failed = normalize_component_id_list(
    component_ids=llm_response["component_ids"],
    id_to_fqdn=id_to_fqdn,
    components=components,
    context="auth-module",
)
```

Typically invoked internally by the higher-level clustering pipeline (e.g., `cluster_leaf_components`), not called directly by end users.
