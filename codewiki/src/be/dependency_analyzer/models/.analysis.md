Defines Pydantic models for representing the output of a repository dependency analysis, including full analysis results and node selection configurations for partial exports.

## Key Components

| Model | Description |
|---|---|
| `AnalysisResult` | Complete output of a repository analysis run |
| `NodeSelection` | Configuration for selecting a subset of nodes for export |

### `AnalysisResult` Fields

| Field | Type | Description |
|---|---|---|
| `repository` | `Repository` | Analyzed repository metadata |
| `functions` | `List[Node]` | All discovered function/class nodes |
| `relationships` | `List[CallRelationship]` | Call relationships between nodes |
| `file_tree` | `Dict[str, Any]` | Hierarchical file structure |
| `summary` | `Dict[str, Any]` | Analysis summary statistics |
| `visualization` | `Dict[str, Any]` | Optional visualization data (default: `{}`) |
| `readme_content` | `Optional[str]` | Repository README content if available |

### `NodeSelection` Fields

| Field | Type | Description |
|---|---|---|
| `selected_nodes` | `List[str]` | Node IDs to include in export |
| `include_relationships` | `bool` | Whether to export relationships (default: `True`) |
| `custom_names` | `Dict[str, str]` | Override display names for nodes |

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.models.analysis import AnalysisResult, NodeSelection

# Build a partial export selection
selection = NodeSelection(
    selected_nodes=["my_module.parse", "my_module.validate"],
    include_relationships=True,
    custom_names={"my_module.parse": "Parser"}
)

# Access analysis output
result: AnalysisResult = analyzer.run(repo_path="/path/to/repo")
print(result.summary)
print(f"Found {len(result.functions)} nodes")
print(f"Found {len(result.relationships)} relationships")
```
