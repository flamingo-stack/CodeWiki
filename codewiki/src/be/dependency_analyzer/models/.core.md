# core.py

Defines the core Pydantic data models used throughout the dependency analysis pipeline, including code entities (`Node`), call graph edges (`CallRelationship`), and repository metadata (`Repository`).

## Key Components

- **`Node`**: Represents a single code entity (function, class, module, etc.) discovered during analysis. Uses a fully-qualified domain name (FQDN) format (`{namespace}.{original_id}`) for its `id` to disambiguate entities across the main repository and its dependencies. Tracks source location (`file_path`, `start_line`, `end_line`), documentation (`has_docstring`, `docstring`), structural metadata (`component_type`, `class_name`, `base_classes`, `parameters`), and outgoing dependencies (`depends_on`). Includes FQDN-related fields (`short_id`, `namespace`, `is_from_deps`) for display and provenance, all defaulted for backward compatibility.
  - `get_display_name()`: Returns `display_name` if set, otherwise falls back to `name`.

- **`CallRelationship`**: Represents a directed call-graph edge between two nodes, identified by `caller` and `callee` IDs. Optionally records the source `call_line` and whether the relationship was successfully `is_resolved` to a known node.

- **`Repository`**: Metadata describing an analyzed repository, including its `url`, `name`, local `clone_path`, and an `analysis_id` linking it to a specific analysis run.

## Usage Example

```python
from core import Node, CallRelationship, Repository

# Define a code entity
node = Node(
    id="main.utils.parse_config",
    name="parse_config",
    component_type="function",
    file_path="/repo/utils.py",
    relative_path="utils.py",
    short_id="utils.parse_config",
    namespace="main",
    is_from_deps=False,
    depends_on={"main.utils.load_file"},
)

print(node.get_display_name())  # "parse_config"

# Define a call relationship between two nodes
call = CallRelationship(
    caller="main.utils.parse_config",
    callee="main.utils.load_file",
    call_line=42,
    is_resolved=True,
)

# Define repository metadata for the analysis run
repo = Repository(
    url="https://github.com/flamingo-stack/CodeWiki",
    name="CodeWiki",
    clone_path="/tmp/codewiki",
    analysis_id="analysis-2024-01-01",
)
```
