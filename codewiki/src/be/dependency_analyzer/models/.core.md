Core data models for the CodeWiki code analysis system, defining the primary structures used to represent parsed code components, their relationships, and repository metadata.

## Key Components

### `Node`
The central model representing a parsed code component (function, class, module, etc.) using a Fully Qualified Domain Name (FQDN) format for unique identification across namespaces.

**Key fields:**
- `id` — FQDN-format identifier: `{namespace}.{original_id}`
- `component_type` — Type of code component (function, class, etc.)
- `file_path` / `relative_path` — Absolute and relative file locations
- `depends_on` — Set of FQDNs this node depends on
- `source_code` — Raw source code of the component
- `start_line` / `end_line` — Line range within the source file
- `has_docstring` / `docstring` — Documentation status and content
- `short_id` / `namespace` / `is_from_deps` — FQDN namespace metadata

### `CallRelationship`
Represents a directional call/dependency edge between two `Node` instances.

**Key fields:**
- `caller` / `callee` — FQDNs of the calling and called nodes
- `call_line` — Source line where the call occurs
- `is_resolved` — Whether the callee was successfully resolved to a known node

### `Repository`
Metadata for a repository being analyzed.

**Key fields:**
- `url` / `name` — Remote URL and display name
- `clone_path` — Local filesystem path of the cloned repository
- `analysis_id` — Unique identifier for the analysis run

## Usage Example

```python
from core import Node, CallRelationship, Repository

# Create a node representing a function
node = Node(
    id="main.utils.parse_config",
    short_id="utils.parse_config",
    namespace="main",
    name="parse_config",
    component_type="function",
    file_path="/repo/src/utils.py",
    relative_path="src/utils.py",
    start_line=10,
    end_line=25,
    has_docstring=True,
    docstring="Parses the application config file.",
    depends_on={"main.utils.load_file"},
)

# Represent a call between two nodes
rel = CallRelationship(
    caller="main.app.main",
    callee="main.utils.parse_config",
    call_line=42,
    is_resolved=True,
)

# Repository under analysis
repo = Repository(
    url="https://github.com/flamingo-stack/CodeWiki",
    name="CodeWiki",
    clone_path="/tmp/codewiki",
    analysis_id="run-2024-001",
)

print(node.get_display_name())  # "parse_config"
```
