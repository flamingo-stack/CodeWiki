Configures colored terminal logging for CodeWiki using `colorama`, providing visually distinct output by log level, timestamp, and component.

## Key Components

- **`ColoredFormatter`** — Custom `logging.Formatter` subclass that applies ANSI colors to log levels (DEBUG→blue, INFO→cyan, WARNING→yellow, ERROR→red, CRITICAL→bright red), timestamps (blue), and messages. Handles exception formatting.
- **`setup_logging(level)`** — Configures the root logger with the colored formatter; clears existing handlers to prevent duplicate output.
- **`setup_module_logging(module_name, level)`** — Configures a named module logger with colored output and `propagate=False` to avoid duplicate log entries.

## Usage Example

```python
import logging
from codewiki.src.be.dependency_analyzer.utils.logging_config import (
    setup_logging,
    setup_module_logging,
)

# Configure root logger (affects all loggers in the application)
setup_logging(level=logging.INFO)
logging.info("Application started")   # green
logging.warning("Low disk space")     # yellow
logging.error("Connection failed")    # red

# Configure a named module logger
logger = setup_module_logging("dependency_analyzer", level=logging.DEBUG)
logger.debug("Parsing module graph")  # blue
logger.info("Analysis complete")      # cyan
```

**Log line format:**

```text
[HH:MM:SS] INFO     Your message here
```

> **Note:** `colorama.init(autoreset=True)` is called at import time, ensuring cross-platform ANSI color support on Windows without manual reset calls.
