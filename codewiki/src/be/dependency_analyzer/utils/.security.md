## Purpose

Provides safe file-reading utilities that prevent path-traversal and symlink-escape attacks when accessing files within a repository root. This is critical for dependency analysis or code-scanning workflows where file paths may originate from untrusted or dynamically generated sources.

## Key Components

- **`_inside(base: Path, target: Path) -> bool`** — Internal helper that resolves both paths and checks whether `target` lies within `base`, using `Path.is_relative_to` (Python 3.9+) with a string-prefix fallback for older versions.
- **`assert_safe_path(base_dir: Path, target: Path)`** — Validates that `target`:
  - Is not a symlink (raises `PermissionError` if so).
  - Resolves to a location inside `base_dir` (raises `PermissionError` if it escapes the repo root).
- **`safe_open_text(base_dir: Path, target: Path, encoding="utf-8") -> str`** — Safely reads a text file's contents:
  - Calls `assert_safe_path` first to validate the path.
  - Opens the file using `os.open` with `O_RDONLY` and `O_NOFOLLOW` (when available) to prevent TOCTOU symlink races at the OS level.
  - Reads the file with `errors="replace"` to gracefully handle invalid encoding bytes.
  - Ensures the file descriptor is always closed, even on error.

## Usage Example

```python
from pathlib import Path
from security import safe_open_text, assert_safe_path

repo_root = Path("/data/repos/my-project")
file_path = repo_root / "src" / "main.py"

try:
    contents = safe_open_text(repo_root, file_path)
    print(contents)
except PermissionError as e:
    print(f"Blocked unsafe access: {e}")

# Validate a path without reading it
try:
    assert_safe_path(repo_root, repo_root / "../etc/passwd")
except PermissionError as e:
    print(f"Rejected: {e}")
```

## Notes

- `O_NOFOLLOW` is only applied on platforms that support it (POSIX systems); on platforms without it, the initial `is_symlink()` check still provides protection.
- Callers should always pass a resolved, trusted `base_dir` to avoid relying on this module to sanitize the base directory itself.
