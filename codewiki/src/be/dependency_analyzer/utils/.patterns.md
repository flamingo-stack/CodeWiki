Defines constants and helper functions for identifying entry points, high-connectivity files, and function definitions across multiple programming languages during code analysis.

## Key Components

### Constants

| Name | Type | Description |
|---|---|---|
| `DEFAULT_IGNORE_PATTERNS` | `set` | Files and directories to exclude during analysis (build artifacts, caches, media, etc.) |
| `DEFAULT_INCLUDE_PATTERNS` | `list` | File extensions to include in analysis |
| `CODE_EXTENSIONS` | `dict` | Maps file extensions to language names |
| `ENTRY_POINT_PATTERNS` | `set` | Exact filenames that are common entry points (e.g., `main.py`, `index.js`) |
| `ENTRY_POINT_PATH_PATTERNS` | `list` | Partial path patterns for entry point detection |
| `HIGH_CONNECTIVITY_PATTERNS` | `set` | Name fragments indicating high-connectivity files (e.g., `router`, `controller`) |
| `FUNCTION_DEFINITION_PATTERNS` | `dict` | Language-specific patterns for locating function definitions |
| `EXPORT_PATTERNS` | `list` | Code snippets indicating exported/public functions |
| `FALLBACK_PATTERNS` | `dict` | Last-resort patterns when primary detection fails |

### Functions

| Function | Description |
|---|---|
| `get_function_patterns_for_language(language)` | Returns function definition patterns for a given language |
| `is_entry_point_file(filename)` | Checks if a filename matches known entry point patterns |
| `is_entry_point_path(filepath)` | Checks if a file path suggests an entry point location |
| `has_high_connectivity_potential(filename, filepath)` | Determines if a file is likely to have many cross-file dependencies |
| `is_critical_function(func_name, code_snippet)` | Identifies critical functions by name or export patterns |
| `find_fallback_entry_points(code_files, max_files)` | Returns candidate entry points when primary patterns yield no matches |

## Usage Example

```python
from patterns import (
    is_entry_point_file,
    has_high_connectivity_potential,
    get_function_patterns_for_language,
    is_critical_function,
)

# Detect entry points
is_entry_point_file("main.py")        # True
is_entry_point_file("utils.py")       # False

# Check connectivity potential
has_high_connectivity_potential("router.ts", "src/api/router.ts")  # True

# Retrieve language-specific function patterns
patterns = get_function_patterns_for_language("python")
# ["def {name}"]

# Identify critical functions
is_critical_function("main")                     # True
is_critical_function("helper", "export default") # True
```
