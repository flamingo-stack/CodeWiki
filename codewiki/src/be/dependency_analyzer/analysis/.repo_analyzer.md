Provides repository structure analysis by traversing directory trees and generating filtered file representations for single or multiple repository paths.

## Key Components

### `RepoAnalyzer`

Main class that builds and filters file trees from local repository paths.

**Constructor Parameters:**
- `include_patterns` — Glob patterns for files to include (defaults to `DEFAULT_INCLUDE_PATTERNS`)
- `exclude_patterns` — Additional glob patterns to exclude, merged with `DEFAULT_IGNORE_PATTERNS`

**Public Methods:**

| Method | Description |
|---|---|
| `analyze_repository_structure(repo_dir)` | Accepts a single path or list of paths; returns a `file_tree` dict and summary stats |

**Private Methods:**

| Method | Description |
|---|---|
| `_analyze_multiple_repositories(repo_dirs)` | Merges multiple repo trees under namespace-prefixed roots |
| `_get_namespace_from_path(repo_path)` | Derives a namespace label from the directory basename |
| `_build_file_tree(repo_dir)` | Recursively walks a directory, skipping symlinks and escaped paths |
| `_should_exclude_path(path, filename)` | Matches path segments against exclude glob patterns |
| `_should_include_file(path, filename)` | Matches file paths against include glob patterns |
| `_count_files(tree)` | Recursively counts file nodes in a tree dict |
| `_calculate_size(tree)` | Recursively sums file sizes in KB |

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.repo_analyzer import RepoAnalyzer

# Single repository
analyzer = RepoAnalyzer(
    include_patterns=["*.py", "*.ts"],
    exclude_patterns=["*.test.py"]
)
result = analyzer.analyze_repository_structure("/path/to/repo")
print(result["summary"])
# {'total_files': 42, 'total_size_kb': 128.5}

# Multiple repositories — trees are merged under namespace roots
result = analyzer.analyze_repository_structure([
    "/path/to/backend",
    "/path/to/frontend"
])
print(result["summary"]["namespaces"])
# ['backend', 'frontend']

# Access the merged tree
tree = result["file_tree"]  # root name: "multi-repo"
```

> **Note:** Symlinks and paths resolving outside the base directory are always rejected, regardless of include/exclude patterns.
