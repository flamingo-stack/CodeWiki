Handles GitHub repository cloning operations, including URL sanitization, shallow cloning to a temporary directory, and cross-platform cleanup of cloned repositories.

## Key Components

| Function | Description |
|---|---|
| `sanitize_github_url(github_url)` | Normalizes raw GitHub URLs or `owner/repo` paths into a clean `https://github.com/owner/repo` format |
| `clone_repository(github_url)` | Shallow-clones (`--depth 1`, `--filter=blob:none`) a repository into a temp directory; returns the temp path |
| `cleanup_repository_safe(repo_dir)` | Removes the cloned temp directory with Windows read-only file handling and retry logic |
| `cleanup_repository(repo_dir)` | Backward-compatible wrapper around `cleanup_repository_safe` |
| `parse_github_url(github_url)` | Extracts `owner`, `name`, `full_name`, and `url` from a GitHub URL into a dict |

## Usage Example

```python
from cloning import clone_repository, cleanup_repository, parse_github_url, sanitize_github_url

# Sanitize various URL formats
clean_url = sanitize_github_url("github.com/flamingo-stack/CodeWiki/tree/main/docs")
# → "https://github.com/flamingo-stack/CodeWiki"

# Parse owner/repo metadata
info = parse_github_url("https://github.com/flamingo-stack/CodeWiki")
# → {"owner": "flamingo-stack", "name": "CodeWiki", "full_name": "flamingo-stack/CodeWiki", ...}

# Clone and process, then clean up
repo_path = clone_repository("https://github.com/flamingo-stack/CodeWiki")
try:
    # work with repo_path files...
    pass
finally:
    cleanup_repository(repo_path)
```

## Notes

- Cloning enforces a **300-second timeout**; raises `RuntimeError` on expiry
- On **Windows**, enables `core.longpaths` and sparse checkout to avoid path-length issues
- Cleanup retries once with forced `chmod` on permission errors, logging warnings on final failure
- Requires `git` in the system `PATH`; detected at import time via `shutil.which("git")`
