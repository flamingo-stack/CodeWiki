# cloning.py

Repository cloning and cleanup utilities for the dependency analysis pipeline. This module handles acquiring a target repository by sanitizing/validating its GitHub URL, cloning it into a temporary directory with a shallow, blob-filtered clone (for speed), and safely tearing down that directory afterward—including handling Windows-specific read-only file permission issues that can otherwise cause cleanup failures.

## Key Components

- **`GIT_EXECUTABLE_PATH`** — Module-level constant resolved via `shutil.which("git")`; used to verify Git is installed before attempting any clone.
- **`sanitize_github_url(github_url)`** — Normalizes a raw URL or `owner/repo` shorthand into a canonical `https://github.com/{owner}/{repo}` form, stripping `www.`, trailing `.git`, and extra path segments.
- **`clone_repository(github_url)`** — Clones the sanitized URL into a new temp directory (prefix `gitprobe_`) using a shallow (`--depth 1`) and blobless (`--filter=blob:none`) clone for performance. Applies Windows-specific long-path and sparse-checkout workarounds. Raises `RuntimeError` on missing Git, timeout (5 min), or clone failure, cleaning up partial clones automatically.
- **`cleanup_repository_safe(repo_dir)`** — Removes a cloned repo directory, handling Windows read-only file errors via `chmod` retries and a fallback recursive permission fix.
- **`cleanup_repository(repo_dir)`** — Thin backward-compatible wrapper around `cleanup_repository_safe`.
- **`parse_github_url(github_url)`** — Extracts `owner`, `name`, and `full_name` from a GitHub URL into a dict for metadata/display purposes.

## Usage Example

```python
from cloning import clone_repository, cleanup_repository, parse_github_url

repo_url = "https://github.com/flamingo-stack/CodeWiki"

# Clone repo to a temp directory
local_path = clone_repository(repo_url)

try:
    info = parse_github_url(repo_url)
    print(f"Cloned {info['full_name']} to {local_path}")
    # ... run downstream dependency analysis on local_path ...
finally:
    # Always clean up, even on analysis failure
    cleanup_repository(local_path)
```

**Note:** Requires a working `git` executable on `PATH`. If not found, `clone_repository` raises `RuntimeError` immediately without attempting a clone.
