## Analysis Service

Centralized service that orchestrates the full repository analysis workflow: cloning a GitHub repository (or reading a local one), analyzing its file structure, running multi-language AST-based call graph analysis, and consolidating results into a structured `AnalysisResult`.

## Key Components

- **`AnalysisService`** — Main service class encapsulating the analysis pipeline.
  - `__init__()` — Initializes the `CallGraphAnalyzer` and tracks temporary directories for cleanup.
  - `analyze_local_repository(repo_path, max_files, languages)` — Analyzes a local folder, optionally filtering by language and capping the number of files, returning nodes/relationships/summary as a dict.
  - `analyze_repository_full(github_url, include_patterns, exclude_patterns)` — Clones a GitHub repo, analyzes structure and call graph, reads README, and returns a complete `AnalysisResult`. Cleans up the clone on success or failure.
  - `analyze_repository_structure_only(github_url, include_patterns, exclude_patterns)` — Lightweight variant that skips call graph generation, returning just file tree and summary stats.
  - `_clone_repository`, `_parse_repository_info`, `_analyze_structure`, `_read_readme_file`, `_analyze_call_graph`, `_filter_supported_languages` (referenced) — Internal helpers for cloning, URL parsing, structure analysis, safe README reading, and language-aware call graph extraction.

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.services.analysis_service import AnalysisService

service = AnalysisService()

# Full analysis of a remote GitHub repository
result = service.analyze_repository_full(
    github_url="https://github.com/flamingo-stack/CodeWiki",
    include_patterns=["*.py", "*.ts"],
    exclude_patterns=["*/tests/*"],
)
print(result.summary["total_functions"])

# Lightweight structure-only analysis
structure = service.analyze_repository_structure_only(
    github_url="https://github.com/flamingo-stack/CodeWiki"
)
print(structure["file_summary"]["total_files"])

# Analyze a local repository folder
local_result = service.analyze_local_repository(
    repo_path="/path/to/local/repo",
    max_files=50,
    languages=["python"],
)
print(local_result["summary"])
```

**Notes:**
- Cloned repositories are automatically cleaned up after analysis, including on failure paths.
- README lookup uses safe-path checks (`assert_safe_path`, `safe_open_text`) to prevent path traversal issues.
- Errors are logged with stack traces and re-raised as `RuntimeError` for callers to handle uniformly.
