# csharp.py

Tree-sitter based dependency analyzer for C# source files. It parses `.cs` files using `tree-sitter-c-sharp` to extract top-level type declarations (classes, interfaces, structs, enums, records, delegates) as `Node` objects, and infers `CallRelationship` edges between them based on inheritance, property/field types, and method parameter types.

## Key Components

- **`TreeSitterCSharpAnalyzer`** — Main analyzer class that parses a C# file's content and builds nodes/relationships on construction.
  - `_get_module_path()` / `_get_relative_path()` / `_get_component_id()` — Compute module-qualified identifiers for components based on file path relative to the repo root.
  - `_analyze()` — Parses the file with tree-sitter and drives node/relationship extraction.
  - `_extract_nodes()` — Recursively walks the syntax tree to identify top-level declarations (`class_declaration`, `interface_declaration`, `struct_declaration`, `enum_declaration`, `record_declaration`, `delegate_declaration`) and creates corresponding `Node` objects, distinguishing `class`, `abstract class`, and `static class` variants.
  - `_extract_relationships()` — Recursively walks the tree to detect:
    - Class base-list inheritance (`caller` extends `callee`)
    - Property declaration type references
    - Field declaration type references
    - Method parameter type references
  - `_is_primitive_type()` — Filters out C# built-in/primitive types (e.g. `int`, `string`, `List`, `Task`) to avoid noisy relationships.
  - `_get_identifier_name_cs()` / `_get_identifier_name()` / `_get_type_name()` — Helpers to extract identifier/type names from various tree-sitter node shapes.
  - `_find_containing_class()` — Walks parent nodes to determine which enclosing type declaration a member belongs to.

- **`analyze_csharp_file(file_path, content, repo_path=None) -> Tuple[List[Node], List[CallRelationship]]`** — Module-level convenience function that instantiates the analyzer and returns extracted nodes and relationships.

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.parsers.csharp import analyze_csharp_file

file_path = "src/Models/User.cs"
content = """
public class User : IEntity
{
    public string Name { get; set; }
    public Address HomeAddress { get; set; }

    public void Save(Repository repo)
    {
        repo.Persist(this);
    }
}
"""

nodes, relationships = analyze_csharp_file(file_path, content, repo_path="/repo/root")

for node in nodes:
    print(node.component_id, node.node_type)

for rel in relationships:
    print(rel.caller, "->", rel.callee, f"(line {rel.call_line}, resolved={rel.is_resolved})")
```

**Note:** Relationships to base classes (via `base_list`) are marked `is_resolved=True` only when the base type matches a top-level node found in the same file; property/field/parameter type relationships are always marked `is_resolved=False`, deferring cross-file resolution to a later pipeline stage.
