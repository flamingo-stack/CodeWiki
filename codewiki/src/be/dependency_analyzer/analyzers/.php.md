## Overview

`php.py` implements a PHP source code analyzer built on `tree-sitter-php`. It parses PHP files to extract structural entities (classes, interfaces, traits, enums, functions, methods) and their dependency relationships (`use` imports, `extends`, `implements`, `new` instantiations, static calls), producing standardized `Node` and `CallRelationship` objects for the dependency graph pipeline. It also resolves PHP namespaces and aliases to fully qualified class names and skips template files (e.g., `.blade.php`, `.phtml`) that shouldn't be treated as regular source.

## Key Components

- **`PHP_PRIMITIVES`**: Set of built-in PHP types/classes (e.g., `string`, `Exception`, `DateTime`) excluded from dependency extraction to avoid noise.
- **`TEMPLATE_PATTERNS` / `TEMPLATE_DIRECTORIES`**: Patterns used to detect and skip template files (Blade, Twig, views directories).
- **`NamespaceResolver`**: Tracks the current namespace and `use` statement aliases, resolving short/partial class names to fully qualified names (FQNs).
  - `register_namespace(ns)`: Sets the active namespace.
  - `register_use(fqn, alias)`: Registers an imported class with optional alias.
  - `resolve(name)`: Resolves a class name reference to its FQN.
- **`TreeSitterPHPAnalyzer`**: Main analyzer class that parses a PHP file and builds the extraction results.
  - `__init__(file_path, content, repo_path)`: Initializes and triggers analysis unless the file is a template.
  - `_analyze()`: Runs the three-pass pipeline — namespace/use extraction, node extraction, relationship extraction.
  - `_extract_namespace_info(node)`: Walks the AST collecting namespace and `use` declarations.
  - `_extract_nodes(node, lines, ...)`: Recursively extracts classes, interfaces, traits, enums, functions, and methods (with PHPDoc docstrings) as `Node` objects.
  - `_get_component_id(name, parent_class)`: Builds a unique ID (`module.path::ClassName.method`) for each extracted entity.
  - `_get_module_path()` / `_get_relative_path()`: Compute module/file path identifiers relative to the repo root.
  - `.nodes` / `.call_relationships`: Public attributes holding extraction results after construction.

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.languages.php import TreeSitterPHPAnalyzer

with open("app/Models/User.php") as f:
    content = f.read()

analyzer = TreeSitterPHPAnalyzer(
    file_path="app/Models/User.php",
    content=content,
    repo_path="/path/to/repo",
)

for node in analyzer.nodes:
    print(node.component_id, node.node_type)

for rel in analyzer.call_relationships:
    print(rel.source, "->", rel.target)
```
