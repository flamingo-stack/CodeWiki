PHP source code analyzer that extracts structural elements and dependency relationships from PHP files using the tree-sitter parsing library.

## Key Components

### `NamespaceResolver`
Resolves PHP class names to fully qualified names (FQN) by tracking:
- Current namespace context via `register_namespace()`
- `use` statement mappings via `register_use()`
- Alias-based name resolution via `resolve()`

### `TreeSitterPHPAnalyzer`
Main analyzer class that parses PHP files and populates:
- `nodes` — list of `Node` objects (classes, interfaces, traits, enums, functions, methods)
- `call_relationships` — list of `CallRelationship` objects (dependencies, instantiations, static calls)

**Internal analysis pipeline (3-pass):**
1. `_extract_namespace_info()` — collects `namespace` and `use` declarations
2. `_extract_nodes()` — extracts structural elements with docstrings and metadata
3. `_extract_relationships()` — maps dependency edges between nodes

### Constants
| Constant | Purpose |
|---|---|
| `PHP_PRIMITIVES` | Built-in types excluded from dependency tracking |
| `TEMPLATE_PATTERNS` | File suffixes (`.blade.php`, `.phtml`) that are skipped |
| `TEMPLATE_DIRECTORIES` | Directory names (e.g., `views`) that trigger skip logic |
| `MAX_RECURSION_DEPTH` | AST traversal depth cap (100) to prevent stack overflow |

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.languages.php import TreeSitterPHPAnalyzer

content = Path("src/Services/UserService.php").read_text()

analyzer = TreeSitterPHPAnalyzer(
    file_path="src/Services/UserService.php",
    content=content,
    repo_path="/path/to/repo"
)

for node in analyzer.nodes:
    print(node.name, node.type)

for rel in analyzer.call_relationships:
    print(rel.caller, "->", rel.callee)
```
