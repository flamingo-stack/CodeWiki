A Tree-sitter-based static analyzer for TypeScript source files that extracts code entities (functions, classes, interfaces, etc.) and their call relationships by parsing the AST.

## Key Components

### `TreeSitterTSAnalyzer`
The main analyzer class that wraps the Tree-sitter TypeScript parser.

**Constructor Parameters:**
- `file_path` (`str`) – Path to the TypeScript file being analyzed
- `content` (`str`) – Raw source code content of the file
- `repo_path` (`str`, optional) – Root path of the repository

**Key Attributes:**
- `nodes` – List of extracted [`Node`](https://github.com/flamingo-stack/CodeWiki/blob/main/codewiki/src/be/dependency_analyzer/models/core.py) objects
- `call_relationships` – List of [`CallRelationship`](https://github.com/flamingo-stack/CodeWiki/blob/main/codewiki/src/be/dependency_analyzer/models/core.py) objects
- `top_level_nodes` – Dict mapping entity names to their top-level `Node` objects

**Core Methods:**

| Method | Description |
|---|---|
| `analyze()` | Entry point — parses the file and populates `nodes` and `call_relationships` |
| `_extract_all_entities()` | Recursively walks the AST to collect all entity definitions |
| `_filter_top_level_declarations()` | Filters entities to only top-level declarations |
| `_is_actually_top_level()` | Determines if an entity lives at the module/program scope |
| `_is_inside_function_body()` | Guards against capturing nested/local declarations |
| `_extract_function_entity()` | Parses `function_declaration` and `generator_function_declaration` nodes |
| `_extract_arrow_function_entity()` | Parses `arrow_function` nodes assigned to variables |
| `_extract_method_entity()` | Parses class `method_definition` nodes |
| `_extract_class_entity()` | Parses `class_declaration` and `abstract_class_declaration` nodes |
| `_extract_ambient_declaration_entity()` | Parses `declare module` / `declare namespace` blocks |

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.typescript import TreeSitterTSAnalyzer

file_path = "src/services/auth.ts"
content = open(file_path).read()

analyzer = TreeSitterTSAnalyzer(
    file_path=file_path,
    content=content,
    repo_path="/path/to/repo"
)

analyzer.analyze()

# Inspect extracted top-level nodes
for node in analyzer.nodes:
    print(node.name, node.type)

# Inspect call relationships
for rel in analyzer.call_relationships:
    print(f"{rel.caller} -> {rel.callee}")
```
