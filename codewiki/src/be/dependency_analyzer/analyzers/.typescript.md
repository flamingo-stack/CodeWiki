# typescript.py

TypeScript/JavaScript dependency analyzer built on `tree-sitter` parsing. This module implements `TreeSitterTSAnalyzer`, which parses TypeScript and JavaScript source files to extract top-level code entities (functions, classes, interfaces, type aliases, enums, variables, exports, etc.) as `Node` objects, along with the call/inheritance/type relationships between them as `CallRelationship` objects. It serves as a core component of the dependency analyzer pipeline, feeding structured data into downstream dependency graph construction.

## Key Components

- **`TreeSitterTSAnalyzer`** — Main analyzer class that initializes the tree-sitter TypeScript parser and orchestrates entity/relationship extraction for a single source file.
  - `__init__(file_path, content, repo_path=None)` — Sets up parser state, `nodes`, `call_relationships`, and `top_level_nodes`; gracefully handles parser initialization failures.
  - `analyze()` — Entry point that parses the file's AST and drives entity extraction, top-level filtering, and relationship extraction.
  - `_extract_all_entities(node, all_entities, depth)` — Recursively walks the AST, dispatching to specialized extractors based on node type (functions, classes, interfaces, enums, type aliases, variable/lexical declarations, export statements, ambient declarations).
  - `_filter_top_level_declarations(all_entities)` — Determines which extracted entities are truly top-level (not nested inside function bodies) and converts them into `Node` objects.
  - `_is_actually_top_level(entity_data)` / `_is_inside_function_body(node)` — Helper predicates used to correctly classify declaration scope, accounting for `export_statement`, `ambient_declaration`, and `module` wrappers.
  - Entity extractors (`_extract_function_entity`, `_extract_arrow_function_entity`, `_extract_method_entity`, `_extract_class_entity`, etc.) — Each builds a dictionary describing a specific entity type (name, parameters, code snippet, display name, async/static flags, line ranges).

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.analyzers.typescript import TreeSitterTSAnalyzer

with open("src/utils/helper.ts", "r", encoding="utf-8") as f:
    content = f.read()

analyzer = TreeSitterTSAnalyzer(
    file_path="src/utils/helper.ts",
    content=content,
    repo_path="/path/to/repo"
)

analyzer.analyze()

for node in analyzer.nodes:
    print(node.name, node.type)

for rel in analyzer.call_relationships:
    print(rel.source, "->", rel.target)
```

Instantiate the analyzer with a file's path and content, call `analyze()`, then inspect `.nodes` (extracted top-level entities) and `.call_relationships` (dependency edges) for use in building the project's dependency graph.
