Parses Java source files using Tree-sitter to extract structural nodes (classes, interfaces, methods, enums, etc.) and their call/dependency relationships for static code analysis.

## Key Components

### `TreeSitterJavaAnalyzer`
Main analyzer class that orchestrates Java file parsing and relationship extraction.

**Constructor Parameters:**
- `file_path` – Absolute path to the Java source file
- `content` – Raw source code string
- `repo_path` – Optional repository root for relative path computation

**Key Methods:**

| Method | Description |
|---|---|
| `_analyze()` | Initializes Tree-sitter parser and triggers node/relationship extraction |
| `_extract_nodes()` | Recursively walks AST to collect classes, interfaces, enums, records, annotations, and methods as `Node` objects |
| `_extract_relationships()` | Detects inheritance (`extends`), implementation (`implements`), field type usage, method invocations, and object instantiation as `CallRelationship` objects |
| `_find_containing_class()` | Walks up the AST to resolve which class a node belongs to |
| `_find_variable_type()` | Searches method blocks and class fields to infer a variable's declared type |
| `_is_primitive_type()` | Filters out Java primitives and common built-ins from relationship tracking |
| `_get_component_id()` | Builds a dotted fully-qualified ID (e.g., `com.example.MyClass.myMethod`) |

**Outputs (instance attributes):**
- `nodes` – `List[Node]` of discovered code components
- `call_relationships` – `List[CallRelationship]` of detected dependencies

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.analyzers.java import TreeSitterJavaAnalyzer

source = Path("src/main/java/com/example/UserService.java").read_text()

analyzer = TreeSitterJavaAnalyzer(
    file_path="src/main/java/com/example/UserService.java",
    content=source,
    repo_path="/workspace/my-repo"
)

for node in analyzer.nodes:
    print(node.id, node.component_type)

for rel in analyzer.call_relationships:
    print(f"{rel.caller} -> {rel.callee} (line {rel.call_line})")
```
