## Java Analyzer (`java.py`)

Parses Java source files using **tree-sitter** to extract structural components (classes, interfaces, enums, records, annotations, methods) and their relationships (inheritance, interface implementation, field types, method calls, object creation) for use in a dependency analysis and clustering pipeline. Extracted components are identified using fully-qualified names in the `module.path::ClassName` format.

## Key Components

- **`TreeSitterJavaAnalyzer`** — Main class that drives parsing and extraction.
  - `__init__(file_path, content, repo_path=None)` — Initializes analyzer and immediately triggers analysis.
  - `_analyze()` — Parses the file content into a tree-sitter AST and orchestrates node/relationship extraction.
  - `_extract_nodes(node, top_level_nodes, lines)` — Recursively walks the AST, identifying declarations (`class`, `interface`, `enum`, `record`, `annotation`, `method`) and building `Node` objects.
  - `_extract_relationships(node, top_level_nodes)` — Recursively walks the AST to detect:
    - Class inheritance (`extends`)
    - Interface implementation (`implements`)
    - Field type usage
    - Method invocations on objects
    - Object creation expressions
  - `_get_module_path()`, `_get_relative_path()`, `_get_component_id()` — Helpers for computing FQDN-style component identifiers relative to the repo root.
  - `_is_primitive_type()`, `_get_identifier_name()`, `_get_type_name()`, `_find_containing_class()`, `_find_variable_type()` — AST navigation utilities to resolve types and containing scopes.
- **Outputs:**
  - `self.nodes: List[Node]` — Extracted structural components.
  - `self.call_relationships: List[CallRelationship]` — Extracted relationships between components (unresolved by default; resolution occurs downstream).

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.analyzers.java import TreeSitterJavaAnalyzer

with open("src/main/java/com/example/UserService.java", "r") as f:
    content = f.read()

analyzer = TreeSitterJavaAnalyzer(
    file_path="src/main/java/com/example/UserService.java",
    content=content,
    repo_path="/path/to/repo"
)

# Extracted components (classes, methods, etc.)
for node in analyzer.nodes:
    print(node.component_id, node.node_type)

# Extracted call/inheritance/usage relationships
for rel in analyzer.call_relationships:
    print(f"{rel.caller} -> {rel.callee}")
```

**Notes:**
- Relationships are emitted with `is_resolved=False`, expecting a downstream resolution pass to match callee names to actual component IDs across the codebase.
- Primitive/common built-in Java types (e.g., `String`, `Integer`, `List`) are filtered out of relationship extraction via `_is_primitive_type()`.
- Requires `tree_sitter` and `tree_sitter_java` packages.
