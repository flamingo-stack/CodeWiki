Parses C source files using Tree-sitter to extract structural nodes (functions, structs, global variables) and their call relationships for dependency graph analysis.

## Key Components

### `TreeSitterCAnalyzer`
Main analyzer class that orchestrates Tree-sitter parsing and AST traversal.

| Method | Description |
|--------|-------------|
| `__init__` | Initializes parser with file path, content, and optional repo root |
| `_analyze` | Builds the Tree-sitter AST and triggers extraction passes |
| `_extract_nodes` | Recursively traverses AST to collect functions, structs, and global variables |
| `_extract_relationships` | Traverses AST to collect call expressions and global variable usages |
| `_find_containing_function` | Walks up the AST to locate the enclosing function for a given node |
| `_is_global_variable` | Confirms a declaration node is not nested inside a function |
| `_is_system_function` | Filters out known C standard/SDL library functions from relationship tracking |

### `analyze_c_file` (module-level)
Convenience factory function that instantiates `TreeSitterCAnalyzer` and returns extracted nodes and relationships.

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.languages.c import analyze_c_file

c_source = """
int counter = 0;

void increment() {
    counter++;
}

int main() {
    increment();
    return 0;
}
"""

nodes, relationships = analyze_c_file(
    file_path="/repo/src/main.c",
    content=c_source,
    repo_path="/repo"
)

for node in nodes:
    print(f"{node.component_type}: {node.name} (line {node.start_line})")
# function: increment (line 4)
# function: main (line 8)

for rel in relationships:
    print(f"{rel.caller} -> {rel.callee} (line {rel.call_line})")
# src.main.main -> increment (line 9)
```

> **Note:** Call relationships to system functions (`printf`, `malloc`, `SDL_Init`, etc.) are automatically filtered out. Cross-file callee resolution is deferred to the upstream `CallGraphAnalyzer`.
