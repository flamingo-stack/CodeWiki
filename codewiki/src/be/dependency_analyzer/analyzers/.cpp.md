C++ source file static analyzer using tree-sitter to extract structural nodes (classes, functions, methods) and call relationships from C++ code for dependency graph construction.

## Key Components

### `TreeSitterCppAnalyzer`

Main analyzer class that parses a C++ source file and populates two collections:

- **`nodes`** (`List[Node]`) — Top-level structural entities: classes, structs, functions, and methods.
- **`call_relationships`** (`List[CallRelationship]`) — Directed edges between nodes representing `calls`, `inherits`, `creates`, and `uses` relationships.

### Core Methods

| Method | Description |
|---|---|
| `_analyze()` | Entry point; builds the tree-sitter parse tree and drives extraction |
| `_extract_nodes()` | Recursive traversal; detects classes, structs, functions, methods, variables, and namespaces |
| `_extract_relationships()` | Recursive traversal; detects call expressions, base class clauses, `new` expressions, and variable references |
| `_get_module_path()` | Converts a file path to a dotted module identifier (e.g. `src.engine.renderer`) |
| `_get_component_id()` | Builds a fully-qualified node ID, optionally scoped to a parent class |
| `_find_containing_class_for_method()` | Walks the AST upward to resolve the enclosing class of a method |
| `_find_containing_function_or_method()` | Walks the AST upward to resolve the enclosing function of a call site |
| `_is_global_variable()` | Returns `True` if a declaration node lives at file/namespace scope |

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.languages.cpp import TreeSitterCppAnalyzer

source = Path("src/engine/renderer.cpp").read_text()

analyzer = TreeSitterCppAnalyzer(
    file_path="src/engine/renderer.cpp",
    content=source,
    repo_path="/workspace/my-project"
)

# Structural nodes (classes, functions, methods)
for node in analyzer.nodes:
    print(node.id, node.component_type)

# Dependency edges
for rel in analyzer.call_relationships:
    print(f"{rel.caller} --{rel.relationship_type}--> {rel.callee} (line {rel.call_line})")
```

## Notes

- Supported file extensions: `.cpp`, `.cc`, `.cxx`, `.hpp`, `.h`
- Relationship types: `calls`, `inherits`, `creates`, `uses`
- Methods defined inside a class body are scoped as `ClassName.method_name` in the component ID
- System/standard-library functions are filtered from call relationships via `_is_system_function()`
