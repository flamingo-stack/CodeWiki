## cpp.py

Implements a C++ source code analyzer built on tree-sitter that parses C++ files and extracts structural components (classes, structs, functions, methods, namespaces, global variables) along with relationships between them (calls, inheritance, instantiation, variable usage). Part of the dependency analysis pipeline that builds a codebase graph across multiple languages.

## Key Components

- **`TreeSitterCppAnalyzer`** — Main analyzer class. Parses a C++ file's content on construction and populates `self.nodes` (list of `Node`) and `self.call_relationships` (list of `CallRelationship`).
  - `_analyze()` — Parses source with `tree_sitter_cpp`, then recursively extracts nodes and relationships from the AST.
  - `_extract_nodes(node, top_level_nodes, lines)` — Recursively walks the syntax tree, identifying `class_specifier`, `struct_specifier`, `function_definition`, `declaration` (global variables), and `namespace_definition` nodes, converting each into a `Node` object.
  - `_extract_relationships(node, top_level_nodes)` — Recursively scans for `call_expression`, `base_class_clause`, `new_expression`, and `identifier` nodes to build `CallRelationship` entries with types `"calls"`, `"inherits"`, `"creates"`, and `"uses"`.
  - Helper methods (`_get_module_path`, `_get_relative_path`, `_get_component_id`, `_is_global_variable`, `_find_containing_class_for_method`, `_find_containing_function_or_method`, `_find_containing_class`, `_is_system_function`) support ID generation and AST context resolution.

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.languages.cpp import TreeSitterCppAnalyzer

with open("src/engine/renderer.cpp", "r") as f:
    content = f.read()

analyzer = TreeSitterCppAnalyzer(
    file_path="src/engine/renderer.cpp",
    content=content,
    repo_path="/path/to/repo"
)

# Extracted structural nodes (classes, structs, functions, namespaces, variables)
for node in analyzer.nodes:
    print(node.component_type, node.name, node.id)

# Extracted relationships (calls, inheritance, instantiation, usage)
for rel in analyzer.call_relationships:
    print(rel.relationship_type, rel.caller, "->", rel.callee)
```

Typically invoked via a higher-level `analyze_cpp_file` entry point in the dependency analyzer pipeline rather than instantiated directly by end users.
