## javascript.py

This module implements a tree-sitter based static analyzer for JavaScript and TypeScript source files. It parses source code into an AST, extracts declarations (classes, interfaces, functions, methods, arrow functions) into `Node` objects, and infers `CallRelationship` edges (function calls, class inheritance, JSDoc-derived type dependencies). It is a core component of the dependency-analysis pipeline used to build the project's dependency graph.

## Key Components

- **`TreeSitterJSAnalyzer`**: Main analyzer class, initialized with a file path, its content, and an optional repo root path. It sets up the tree-sitter JavaScript grammar/parser and exposes methods to run analysis and access extracted results.
  - `analyze()`: Parses the file content and populates `self.nodes` and `self.call_relationships`.
  - `_extract_functions(node)` / `_traverse_for_functions(node)`: Recursively walk the AST to find top-level classes, interfaces, function declarations (including generators), arrow functions assigned via `lexical_declaration`, and exported functions.
  - `_extract_methods_from_class(class_node, class_name)`: Extracts methods and arrow-function class fields from a class body.
  - `_extract_class_declaration(node)`: Builds a `Node` for class/abstract class/interface declarations, including inherited base classes from `class_heritage`.
  - `_create_method_node(node, method_name, class_name)`: Builds a `Node` for class methods/fields.
  - `_get_component_id`, `_get_module_path`, `_get_relative_path`: Helpers to compute unique component identifiers and normalized module/file paths relative to the repo root.
  - `_find_containing_class(node)`: Walks up the AST to determine if a node is nested inside a class/interface.
  - `_add_relationship(relationship)`: Deduplicates and stores `CallRelationship` objects using a `(caller, callee, call_line)` key.

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.analyzers.javascript import TreeSitterJSAnalyzer

with open("src/utils/helpers.ts", "r", encoding="utf-8") as f:
    content = f.read()

analyzer = TreeSitterJSAnalyzer(
    file_path="src/utils/helpers.ts",
    content=content,
    repo_path="/path/to/repo",
)
analyzer.analyze()

for node in analyzer.nodes:
    print(node.component_type, node.name, node.start_line, node.end_line)

for rel in analyzer.call_relationships:
    print(rel.caller, "->", rel.callee, "at line", rel.call_line)
```

Note: If the tree-sitter JavaScript grammar fails to load, `self.parser` is set to `None`, and `analyze()` will log a warning and skip processing rather than raising an exception.
