Analyzes JavaScript/TypeScript source files using Tree-sitter to extract function declarations, class hierarchies, method definitions, and call relationships into structured `Node` and `CallRelationship` models.

## Key Components

### `TreeSitterJSAnalyzer`
Main analyzer class that parses JS/TS/JSX/TSX files via Tree-sitter.

| Method | Description |
|---|---|
| `__init__` | Initializes Tree-sitter JS parser and internal state |
| `analyze()` | Entry point: parses AST, extracts nodes and relationships |
| `_extract_functions()` | Traverses AST to collect top-level functions, classes, arrow functions |
| `_extract_methods_from_class()` | Extracts method and arrow-function field definitions from class bodies |
| `_extract_class_declaration()` | Builds a `Node` for class, abstract class, or interface declarations |
| `_create_method_node()` | Builds a `Node` for a method or arrow-function field |
| `_add_relationship()` | Deduplicates and stores a `CallRelationship` |
| `_get_module_path()` | Converts file path to dotted module identifier, stripping JS/TS extensions |
| `_get_component_id()` | Generates a unique scoped ID (e.g., `module.ClassName.methodName`) |
| `_find_containing_class()` | Walks parent AST nodes to determine enclosing class scope |

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.javascript import TreeSitterJSAnalyzer

source = Path("src/services/auth.ts").read_text()

analyzer = TreeSitterJSAnalyzer(
    file_path="src/services/auth.ts",
    content=source,
    repo_path="/workspace/my-project"
)

analyzer.analyze()

for node in analyzer.nodes:
    print(f"{node.node_type}: {node.id} (lines {node.start_line}–{node.end_line})")

for rel in analyzer.call_relationships:
    print(f"{rel.caller} → {rel.callee} at line {rel.call_line}")
```
