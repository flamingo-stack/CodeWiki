Parses source code repositories to extract code components, build dependency graphs, and map inter-component relationships across single or multiple repository paths.

## Key Components

### `DependencyParser`

Main parser class that orchestrates AST-based analysis of multi-language repositories.

**Constructor Parameters:**
- `repo_path` — Single path (`str`) or list of paths (`List[str]`) to repositories
- `include_patterns` — Optional file glob patterns to include (e.g., `["*.py", "*.cs"]`)
- `exclude_patterns` — Optional file/directory patterns to exclude (e.g., `["*Tests*"]`)

**Key Methods:**

| Method | Description |
|---|---|
| `parse_repository()` | Entry point; dispatches to single or multi-path parsing |
| `_parse_single_repository()` | Parses one repo; returns `Dict[str, Node]` |
| `_parse_multiple_repositories()` | Merges components from all repos with namespace prefixes |
| `_get_namespace_from_path()` | Derives namespace label from directory name |
| `_build_namespaced_components()` | Creates `Node` objects with `{namespace}.{id}` FQDNs |
| `_resolve_cross_namespace_dependencies()` | Wires cross-repo dependency edges (truncated in source) |

**Internal State:**
- `self.components` — `Dict[str, Node]` of all parsed components
- `self.modules` — `Set[str]` of discovered module paths

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.ast_parser import DependencyParser

# Single repository
parser = DependencyParser(
    repo_path="/path/to/repo",
    include_patterns=["*.py"],
    exclude_patterns=["*test*"]
)
components = parser.parse_repository()

# Multiple repositories (namespaced)
parser = DependencyParser(
    repo_path=["/path/to/frontend", "/path/to/backend"],
    include_patterns=["*.ts", "*.py"]
)
components = parser.parse_repository()
# Keys follow pattern: "frontend.module.ClassName", "backend.module.fn"

for fqdn, node in components.items():
    print(f"{fqdn} depends on: {node.depends_on}")
```

## Notes

- Multi-repo mode namespaces all component IDs as `{dir_name}.{original_id}` to prevent collisions
- `repo_index=0` marks primary repo components; `repo_index>0` sets `is_from_deps=True` on nodes
- Delegates file traversal and call graph extraction to [`AnalysisService`](https://github.com/flamingo-stack/CodeWiki/blob/main/codewiki/src/be/dependency_analyzer/analysis/analysis_service.py)
