## ast_parser.py

This module implements Stage 2 of the dependency analysis pipeline: parsing one or more repositories into Abstract Syntax Tree (AST)-derived structural and call-graph representations, then building a namespaced, fully-qualified dependency graph of code components (functions, classes, etc.) suitable for downstream clustering, summarization, and documentation generation.

## Key Components

- **`DependencyParser`**: Main class orchestrating repository parsing. Supports both single-path and multi-path (multiple repository) modes.
  - `parse_repository(filtered_folders=None)`: Entry point that dispatches to single- or multi-repository parsing based on the number of paths provided.
  - `_parse_single_repository(repo_path, filtered_folders=None)`: Analyzes structure and call graph for one repository, builds components without namespacing.
  - `_parse_multiple_repositories(filtered_folders=None)`: Analyzes each repository, namespaces its components (using directory name as prefix), merges all components, and resolves cross-namespace dependency edges.
  - `_get_namespace_from_path(repo_path)`: Derives a namespace string from a repository's directory name.
  - `_build_namespaced_components(call_graph_result, namespace, namespace_mapping, repo_index)`: Constructs `Node` objects keyed by fully-qualified domain name (FQDN) in `namespace.original_id` format, tracking `short_id`, `namespace`, and `is_from_deps` metadata.

- **`Node`** (imported from `codewiki.src.be.dependency_analyzer.models.core`): Data model representing a single code component (function, class, etc.) with metadata such as source location, docstring, parameters, and FQDN identifiers.

- **`AnalysisService`** (imported from `codewiki.src.be.dependency_analyzer.analysis.analysis_service`): Underlying service providing `_analyze_structure` (file discovery) and `_analyze_call_graph` (function/class extraction and relationship detection).

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.ast_parser import DependencyParser

# Single repository mode
parser = DependencyParser(
    repo_path="/path/to/repo",
    include_patterns=["*.py", "*.cs"],
    exclude_patterns=["*Tests*"]
)
components = parser.parse_repository()

# Multi-repository mode (e.g., main app + dependency)
parser = DependencyParser(
    repo_path=["/path/to/main-app", "/path/to/shared-lib"]
)
components = parser.parse_repository()

# Inspect resulting components
for fqdn, node in components.items():
    print(fqdn, node.component_type, node.namespace)
```
