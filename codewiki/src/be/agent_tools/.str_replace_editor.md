A string replacement editor tool for viewing and editing source code files, adapted from SWE-agent. It provides file viewing, targeted text replacement, and optional linting capabilities for use within the CodeWiki AI agent pipeline.

## Key Components

- **`maybe_truncate(content, truncate_after)`** — Clips content exceeding `MAX_RESPONSE_LEN` (16,000 chars) and appends a context-saving notice.
- **`Flake8Error`** — Dataclass representing a single flake8 lint error, with a `from_line()` classmethod for parsing raw flake8 output.
- **`_update_previous_errors(previous_errors, replacement_window, replacement_n_lines)`** — Adjusts lint error line numbers after an edit, filtering out errors inside the replaced window.
- **`format_flake8_output(...)`** — Filters and formats flake8 output, suppressing pre-existing errors so only newly introduced issues are surfaced.
- **`flake8(file_path)`** — Runs flake8 with a curated set of checks (`F821`, `F822`, `F831`, `E111`–`E113`, `E999`, `E902`) on `.py` files.
- **`Filemap`** — Uses `tree-sitter` to parse Python files and produce a condensed filemap, eliding function bodies longer than 5 lines.
- **`WindowExpander`** — Extends view/edit windows to natural code boundaries (functions, classes, decorators, blank lines) rather than arbitrary line counts.

## Usage Example

```python
from codewiki.tools.str_replace_editor import maybe_truncate, flake8, Flake8Error

# Truncate long file content before sending to LLM context
content = Path("large_file.py").read_text()
safe_content = maybe_truncate(content, truncate_after=16000)

# Run lint checks on an edited file
lint_output = flake8("my_module.py")

# Parse and inspect individual errors
if lint_output:
    error = Flake8Error.from_line(lint_output.splitlines()[0].strip())
    print(f"Line {error.line_number}: {error.problem}")
```

## Notes

- `USE_LINTER` and `USE_FILEMAP` are feature flags defaulting to `False`; enable them to activate linting and filemap views.
- `stdout` is reconfigured to UTF-8 at import time to avoid ASCII encoding errors on non-ASCII source files.
