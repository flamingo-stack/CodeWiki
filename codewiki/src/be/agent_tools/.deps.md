Defines the `CodeWikiDeps` dataclass, which serves as the shared dependency/context container passed throughout the CodeWiki documentation generation pipeline.

## Key Components

### `CodeWikiDeps`
A `dataclass` that bundles all runtime state and configuration needed by the documentation agents. Fields include:

| Field | Type | Description |
|---|---|---|
| `absolute_docs_path` | `str` | Absolute path to the output docs directory |
| `absolute_repo_path` | `str` | Absolute path to the source repository root |
| `registry` | `dict` | Registry of already-documented modules/files |
| `components` | `dict[str, Node]` | Parsed dependency graph nodes keyed by identifier |
| `path_to_current_module` | `list[str]` | Breadcrumb path to the module currently being processed |
| `current_module_name` | `str` | Name of the module currently being documented |
| `module_tree` | `dict[str, any]` | Hierarchical tree of all discovered modules |
| `max_depth` | `int` | Maximum traversal depth for the dependency analyzer |
| `current_depth` | `int` | Current traversal depth during recursive processing |
| `config` | `Config` | LLM and pipeline configuration settings |
| `custom_instructions` | `str` | Optional user-supplied instructions for the LLM agents |

## Usage Example

```python
from codewiki.src.be.dependency_analyzer.models.core import Node
from codewiki.src.config import Config
from codewiki.src.be.deps import CodeWikiDeps

deps = CodeWikiDeps(
    absolute_docs_path="/output/docs",
    absolute_repo_path="/home/user/my-repo",
    registry={},
    components={"main.py": Node(...)},
    path_to_current_module=["src", "main"],
    current_module_name="main",
    module_tree={"src": {"main": {}}},
    max_depth=5,
    current_depth=0,
    config=Config(...),
    custom_instructions="Focus on public API surfaces only.",
)
```
