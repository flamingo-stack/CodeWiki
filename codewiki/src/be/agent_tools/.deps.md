## Overview

This module defines `CodeWikiDeps`, a shared dependency container (dataclass) used to pass contextual state and configuration to agent tools throughout the CodeWiki documentation generation pipeline. It centralizes paths, component metadata, module tree position, and configuration so tools operate consistently against the same context.

## Key Components

- **`CodeWikiDeps`** — A `dataclass` encapsulating:
  - `absolute_docs_path` / `absolute_repo_path`: filesystem paths for docs output and source repo.
  - `registry`: a dictionary tracking known entities/components across the pipeline.
  - `components`: mapping of component names to `Node` instances (from `codewiki.src.be.dependency_analyzer.models.core`).
  - `path_to_current_module`: list representing the current position within the module tree hierarchy.
  - `current_module_name`: name of the module currently being processed.
  - `module_tree`: nested dictionary representing the overall module hierarchy.
  - `max_depth` / `current_depth`: recursion/traversal depth limits and tracking.
  - `config`: a `Config` instance holding LLM configuration.
  - `custom_instructions`: optional string for user-supplied generation instructions (defaults to `None`).

## Usage Example

```python
from codewiki.src.deps import CodeWikiDeps
from codewiki.src.config import Config

deps = CodeWikiDeps(
    absolute_docs_path="/repo/docs",
    absolute_repo_path="/repo",
    registry={},
    components={},
    path_to_current_module=["src", "utils"],
    current_module_name="utils",
    module_tree={},
    max_depth=5,
    current_depth=1,
    config=Config(),
    custom_instructions="Focus on public API usage.",
)

# Pass to an agent tool that expects a CodeWikiDeps instance
def generate_docs(deps: CodeWikiDeps):
    print(f"Generating docs for {deps.current_module_name} at depth {deps.current_depth}")

generate_docs(deps)
```

This container is typically constructed once per module during traversal and passed into agent tool functions to provide consistent access to shared pipeline state.
