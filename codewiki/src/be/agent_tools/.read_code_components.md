Retrieves source code for one or more code components by their fully-qualified IDs, returning their raw source as a formatted string for use by the CodeWiki AI agent.

## Key Components

- **`read_code_components(ctx, component_ids)`** — Async function that accepts a `RunContext[CodeWikiDeps]` and a list of component ID strings. Looks up each ID in `ctx.deps.components` and returns a concatenated string of source code blocks or not-found messages.
- **`read_code_components_tool`** — A `pydantic_ai.Tool` instance wrapping the function above, registered with the name `"read_code_components"` and configured with `takes_ctx=True` to receive agent dependencies at runtime.

## Usage Example

```python
from codewiki.src.be.agent_tools.read_code_components import read_code_components_tool

# Register the tool with your pydantic-ai agent
agent = Agent(
    model="openai:gpt-4o",
    deps_type=CodeWikiDeps,
    tools=[read_code_components_tool],
)

# The agent can then invoke it with component IDs like:
component_ids = [
    "sweagent.types.AgentRunResult",
    "sweagent.environment.SWEEnv",
]
# Returns formatted source blocks, e.g.:
# "# Component sweagent.types.AgentRunResult:\nclass AgentRunResult:..."
```

Component IDs follow the convention `<dotted.module.path>.<ComponentName>`, matching keys stored in `CodeWikiDeps.components`. If a component ID is not found, a `# Component <id> not found` placeholder is included in the output rather than raising an error.
