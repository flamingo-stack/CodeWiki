# read_code_components.py

Defines an agent tool that retrieves the raw source code for one or more CodeWiki components identified by their component IDs. This tool allows an AI agent to fetch precise source snippets during documentation generation rather than relying on summaries.

## Key Components

- **`read_code_components`** — Async function that accepts a `RunContext[CodeWikiDeps]` and a list of `component_ids`. For each ID, it looks up the component in `ctx.deps.components`; if found, it appends the component's stripped `source_code` (prefixed with a header comment); if not found, it appends a "not found" message. Returns all results joined by newlines.
- **`read_code_components_tool`** — A `pydantic_ai.Tool` instance wrapping `read_code_components`, registered with the name `"read_code_components"` and configured with `takes_ctx=True` so it receives the `RunContext` at invocation time.

## Usage Example

```python
from codewiki.src.be.agent_tools.read_code_components import read_code_components_tool

# Register the tool with an agent
agent = Agent(
    model="...",
    tools=[read_code_components_tool],
    deps_type=CodeWikiDeps,
)

# The agent can invoke it with component IDs like:
# component_ids = ["sweagent.types.AgentRunResult", "sweagent.utils.parse_config"]
result = await agent.run(
    "Show me the source of AgentRunResult",
    deps=CodeWikiDeps(components={...}),
)
```

Component IDs follow the format `<module.path>.<ComponentName>`, e.g. `sweagent.types.AgentRunResult`, where the prefix is the path to the component and the suffix is its name. The tool is typically used by documentation-generation agents that need to inspect actual implementation code before writing explanations.
