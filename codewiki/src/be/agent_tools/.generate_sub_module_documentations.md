## Overview

This module implements the recursive agent-dispatch mechanism used by CodeWiki to decompose a code module into smaller sub-modules and generate documentation for each. It is exposed as `generate_sub_module_documentation_tool`, a `pydantic_ai` `Tool` invoked by the top-level documentation agent when a module is deemed too complex to document as a single unit.

Core responsibilities:
- **ID normalization**: LLMs return component identifiers as integer IDs (from an ID-based clustering system) rather than full FQDNs. This module resolves those IDs back to canonical FQDN strings present in `deps.components`.
- **Module tree maintenance**: Updates the shared in-memory `module_tree` structure with newly created sub-modules and their associated components.
- **Recursive agent spawning**: For each sub-module, creates a nested `pydantic_ai.Agent` — either a "leaf" agent (terminal, simpler prompt/tools) or a non-leaf agent (can further recurse) depending on module complexity, token count, and recursion depth — and runs it to produce documentation.

## Key Components

- **`generate_sub_module_documentation(ctx, sub_module_specs)`** — Async tool function. Takes a mapping of sub-module names to lists of component IDs/FQDNs, normalizes them, updates the module tree, and dispatches a sub-agent per sub-module to write documentation.
- **`generate_sub_module_documentation_tool`** — The `Tool` instance wrapping the above function, with a strict description enforcing that callers pass integer component IDs (not class names or FQDN strings).

## Usage Example

```python
from codewiki.src.be.agent_tools.generate_sub_module_documentations import (
    generate_sub_module_documentation_tool,
)
from pydantic_ai import Agent

# Registered as a tool on the top-level documentation agent
top_level_agent = Agent(
    model=fallback_models,
    deps_type=CodeWikiDeps,
    tools=[generate_sub_module_documentation_tool],
    system_prompt=SYSTEM_PROMPT,
)

# The LLM invokes this tool with specs like:
# {"Authentication": [0, 1], "Configuration": [2, 3]}
result = await top_level_agent.run(user_prompt, deps=codewiki_deps)
```

Each sub-module's documentation is recursively generated by nested agents and saved as `<sub_module_name>.md` in the working directory, with the module tree updated in `deps.module_tree` to reflect the new hierarchy.
