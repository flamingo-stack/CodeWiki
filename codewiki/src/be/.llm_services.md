LLM service factory module that creates and configures AI model clients (main, fallback, and cluster) using `pydantic-ai` and OpenAI-compatible providers, with built-in request counting and multi-provider support.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `create_main_model` | Function | Creates the primary `OpenAIModel` for documentation generation |
| `create_fallback_model` | Function | Creates a secondary `OpenAIModel` used when the main model fails |
| `create_cluster_model` | Function | Creates an `OpenAIModel` dedicated to module clustering operations |
| `CountingFallbackModel` | Class | Extends `FallbackModel` to log a progress message every 100 LLM requests |
| `create_fallback_models` | Function | Chains main + fallback into a `CountingFallbackModel` |
| `create_openai_client` | Function | Returns a raw `OpenAI` client routed to the correct provider based on model name |
| `get_max_output_tokens` | Function | Reads `MAX_OUTPUT_TOKENS` env var, defaulting to `16384` |
| `get_model_max_token_field` | Function | Returns the correct token parameter name (`max_tokens` vs `max_completion_tokens`) per stage |
| `reset_request_counter` | Function | Resets the global request counter for a named module |
| `increment_request_counter` | Function | Increments the counter and logs progress at every 100 requests |

## Usage Example

```python
from codewiki.src.config import Config
from codewiki.src.llm_services import (
    create_fallback_models,
    create_cluster_model,
    create_openai_client,
    reset_request_counter,
)

config = Config(
    main_model="gpt-4o-mini",
    main_base_url="https://api.openai.com/v1",
    main_api_key="sk-...",
    fallback_model="gpt-3.5-turbo",
    fallback_base_url="https://api.openai.com/v1",
    fallback_api_key="sk-...",
    cluster_model="gpt-4o-mini",
    cluster_base_url="https://api.openai.com/v1",
    cluster_api_key="sk-...",
)

# Track requests for a module
reset_request_counter("my_module")

# Chain main + fallback for generation
model = create_fallback_models(config)

# Cluster-specific model
cluster_model = create_cluster_model(config)

# Raw OpenAI client (e.g., for reasoning models needing max_completion_tokens)
client = create_openai_client(config, model=config.main_model)
```

> **Note on reasoning models:** For models like `o3`/`o3-mini` that require `max_completion_tokens` instead of `max_tokens`, use `get_model_max_token_field(stage)` to retrieve the correct parameter name and call the API directly via `create_openai_client`.
