# llm_services.py

Factory module for creating configured LLM clients used throughout CodeWiki's generation pipeline. It builds `pydantic-ai` `OpenAIModel` instances (main, fallback, and cluster models) using per-provider configuration (base URL, API key, temperature, max tokens), and wraps them in a `FallbackModel` chain with request-count logging for observability.

## Key Components

- **`create_main_model(config)`** — Builds the primary generation `OpenAIModel` from `config.main_*` settings. Raises `ValueError` if `main_base_url` or `main_api_key` is missing.
- **`create_fallback_model(config)`** — Builds the fallback `OpenAIModel` from `config.fallback_*` settings, used when the main model fails.
- **`create_cluster_model(config)`** — Builds the model used for module clustering, from `config.cluster_*` settings.
- **`create_fallback_models(config)`** — Combines main and fallback models into a `CountingFallbackModel` chain.
- **`CountingFallbackModel`** — Subclass of `pydantic_ai.models.fallback.FallbackModel` that increments a global request counter on every call.
- **`create_openai_client(config, model=None)`** — Creates a raw `openai.OpenAI` client (used for direct API calls, e.g. reasoning models needing `max_completion_tokens`) selecting the appropriate base URL/key based on the model name (truncated in source, but selects among cluster/main/fallback settings).
- **`get_max_output_tokens()`** — Reads `MAX_OUTPUT_TOKENS` env var (default `16384`).
- **`get_model_max_token_field(stage)`** — Reads stage-specific env vars (`CODEWIKI_CLUSTER_MAX_TOKEN_FIELD`, etc.) to determine whether to use `max_tokens` or `max_completion_tokens` (for reasoning models like o3).
- **`reset_request_counter(module_name)`** / **`increment_request_counter()`** — Track and periodically log (every 100 requests) LLM call volume per module.

## Usage Example

```python
from codewiki.src.config import Config
from codewiki.src.llm_services import (
    create_fallback_models,
    create_cluster_model,
    reset_request_counter,
)

config = Config(
    main_model="gpt-4o-mini",
    main_base_url="https://api.openai.com/v1",
    main_api_key="sk-...",
    fallback_model="claude-haiku",
    fallback_base_url="https://api.anthropic.com/v1",
    fallback_api_key="sk-ant-...",
)

# Reset counter before processing a new module
reset_request_counter(module_name="auth_service")

# Build a main+fallback model chain for generation
model = create_fallback_models(config)

# Build a separate model for clustering
cluster_model = create_cluster_model(config)
```

Both `main_base_url`/`main_api_key` and `fallback_base_url`/`fallback_api_key` (and their `cluster_*` equivalents) must be explicitly set in `Config`, or a descriptive `ValueError` is raised guiding CLI/config-file setup.
