Factory module for creating and managing configured LLM clients using pydantic-ai, supporting multi-model setups with main, fallback, and cluster model configurations.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `create_main_model` | Function | Creates the primary LLM model (`OpenAIModel`) from `Config` |
| `create_fallback_model` | Function | Creates the fallback LLM model from `Config` |
| `create_cluster_model` | Function | Creates the clustering-stage LLM model from `Config` |
| `create_fallback_models` | Function | Returns a `CountingFallbackModel` chaining main → fallback |
| `create_openai_client` | Function | Creates a raw `OpenAI` client, routing to the correct provider based on model stage |
| `CountingFallbackModel` | Class | `FallbackModel` subclass that logs progress every 100 requests |
| `get_max_output_tokens` | Function | Reads `MAX_OUTPUT_TOKENS` env var, defaults to `16384` |
| `get_model_max_token_field` | Function | Returns correct token param name (`max_tokens` vs `max_completion_tokens`) per stage |
| `reset_request_counter` | Function | Resets the global LLM request counter for a named module |
| `increment_request_counter` | Function | Increments counter and logs every 100 requests |

## Usage Example

```python
from codewiki.src.config import Config
from codewiki.src.llm_services import (
    create_fallback_models,
    create_cluster_model,
    create_openai_client,
    reset_request_counter,
)

config = Config(
    main_model="gpt-4o-mini",
    main_base_url="https://api.openai.com/v1",
    main_api_key="sk-...",
    fallback_model="gpt-3.5-turbo",
    fallback_base_url="https://api.openai.com/v1",
    fallback_api_key="sk-...",
    cluster_model="gpt-4o-mini",
    cluster_base_url="https://api.openai.com/v1",
    cluster_api_key="sk-...",
)

# Chained main → fallback model for generation
reset_request_counter("doc_generation")
model = create_fallback_models(config)

# Dedicated cluster model for module clustering
cluster_model = create_cluster_model(config)

# Raw OpenAI client routed by model name
client = create_openai_client(config, model=config.main_model)
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `MAX_OUTPUT_TOKENS` | `16384` | Max tokens for LLM responses |
| `CODEWIKI_GENERATION_MAX_TOKEN_FIELD` | `max_tokens` | Token param name for generation stage |
| `CODEWIKI_CLUSTER_MAX_TOKEN_FIELD` | `max_tokens` | Token param name for cluster stage |
| `CODEWIKI_FALLBACK_MAX_TOKEN_FIELD` | `max_tokens` | Token param name for fallback stage |

> **Note:** Reasoning models such as `o3` and `o3-mini` require `max_completion_tokens` instead of `max_tokens`. Set the appropriate `CODEWIKI_*_MAX_TOKEN_FIELD` env var accordingly.
