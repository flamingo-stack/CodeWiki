Builds and injects the system prompt used by the AI documentation assistant, combining Flamingo guidelines, validation rules, and structured instructions for generating module documentation.

## Key Components

### `format_module_display_name(module_name: str) -> str`
Converts kebab-case or snake_case module names into Title Case display names for use in documentation headings and body text.

### `SYSTEM_PROMPT` (module-level constant)
An f-string that assembles the full system prompt by concatenating three dynamically loaded sections:
- `_CUSTOM_INSTRUCTIONS_SECTION` — repository-specific instructions from environment
- `_GUIDELINES_SECTION` — Flamingo markdown formatting guidelines
- `_VALIDATION_RULES_SECTION` — markdown validation rules

These are injected ahead of hardcoded `<ROLE>`, `<OBJECTIVES>`, `<MODULE_NAMING>`, `<DOCUMENTATION_STRUCTURE>`, and `<DETAILED_MERMAID_SYNTAX>` XML blocks.

### Private Section Globals
`_CUSTOM_INSTRUCTIONS_SECTION`, `_GUIDELINES_SECTION`, and `_VALIDATION_RULES_SECTION` are loaded at import time via [`flamingo_guidelines`](https://github.com/flamingo-stack/CodeWiki/blob/main/codewiki/src/be/flamingo_guidelines.py) helpers that read from environment variables.

## Usage Example

```python
from codewiki.src.be.prompt_template import SYSTEM_PROMPT, format_module_display_name

# Format a module name for display in generated docs
display = format_module_display_name("gateway-service-core")
# Returns: "Gateway Service Core"

# Pass the assembled system prompt to an LLM client
response = llm_client.chat(
    system=SYSTEM_PROMPT,
    user=f"Document the module: {display}"
)
```

> **Note:** `SYSTEM_PROMPT` uses `{{module_name}}` as a literal placeholder (escaped braces) intended for downstream `.format()` calls, not evaluated at import time.
