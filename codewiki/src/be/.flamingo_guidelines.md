# flamingo_guidelines.py

Loads and sanitizes Flamingo-specific markdown formatting guidelines, repository custom instructions, and markdown validation rules from environment variables, then formats them for safe injection into LLM prompt templates. This module is the single source of truth for prompt-time guideline injection, ensuring braces in dynamically loaded content don't collide with Python's `str.format()` placeholder syntax.

## Key Components

- **`load_flamingo_guidelines()`** — Reads guidelines markdown from the file path in `FLAMINGO_MARKDOWN_GUIDELINES_PATH` env var. Returns `""` if unset/missing.
- **`load_custom_instructions()`** — Reads repo-specific instructions directly from `CUSTOM_REPO_INSTRUCTIONS` env var (raw text, not a file path) and sanitizes it.
- **`load_validation_rules()`** — Reads markdown validation rules from the file path in `VALIDATION_RULES_PATH` env var.
- **`sanitize_problematic_patterns(text)`** — Normalizes GitHub Actions syntax (`${{...}}` → `${...}`) without altering intentional brace escaping.
- **`sanitize_and_escape_format_braces(text)`** — Sanitizes text, then doubles all curly braces (`{` → `{{`) for `.format()` safety, while preserving numeric placeholders like `{0}`, `{1}` as literal text via temporary markers.
- **`escape_format_braces(text)`** — Deprecated alias delegating to `sanitize_and_escape_format_braces()`.
- **`get_guidelines_section()`** — Returns a formatted, brace-escaped guidelines block wrapped with a markdown header, ready for prompt concatenation.
- **Module-level constants** — `FLAMINGO_MARKDOWN_GUIDELINES` and `CUSTOM_REPO_INSTRUCTIONS` are loaded once at import time.

## Usage Example

```python
from codewiki.src.be.flamingo_guidelines import (
    get_guidelines_section,
    load_custom_instructions,
)

custom_instructions = load_custom_instructions()

prompt = (
    f"{custom_instructions}"
    f"{get_guidelines_section()}"
    "Generate documentation for the following code...\n"
)

# Safe to call .format() later since guideline braces are pre-escaped
final_prompt = prompt.format(module_name="flamingo_guidelines")
```

**Note:** All sanitization happens once, at load time in this module—downstream code should not re-sanitize env-sourced text, avoiding double-escaping bugs.
