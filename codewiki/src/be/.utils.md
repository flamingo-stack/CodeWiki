Utility module providing helper functions for module complexity detection, token counting, and Mermaid diagram validation/extraction used during documentation generation.

## Key Components

- **`is_complex_module(components, core_component_ids)`** - Determines if a module is "complex" by checking whether its core components span more than one source file.
- **`count_tokens(text)`** - Counts tokens in a string using `tiktoken`'s GPT-4 encoding, useful for staying within LLM context limits.
- **`validate_mermaid_diagrams(md_file_path, relative_path)`** - Async function that extracts and validates all Mermaid diagrams in a markdown file, returning a human-readable summary of syntax errors (if any).
- **`extract_mermaid_blocks(content)`** - Parses markdown content and returns a list of `(line_number, diagram_content)` tuples for each fenced `mermaid` code block.
- **`validate_single_diagram(diagram_content, diagram_num, line_start)`** - Async function that validates one diagram using `mermaid_parser` (primary) with fallback to `mermaid-py`, returning a formatted error message pinpointing the failing line with surrounding source context.
- **`extract_and_save_mermaid_diagrams(md_file_path, diagrams_dir)`** - Extracts diagrams from a markdown file, infers diagram type (flowchart, sequence, class, etc.), and saves each as a standalone `.mmd` file.
- **`create_diagrams_readme(diagrams_dir, diagram_files)`** - Generates an index `README.md` for a directory of extracted diagram files (implementation truncated in source).

## Usage Example

```python
from utils import count_tokens, is_complex_module, validate_mermaid_diagrams

# Count tokens before sending text to an LLM
token_count = count_tokens("Some documentation text to embed in a prompt")

# Check if a module spans multiple files (i.e., is "complex")
complex_flag = is_complex_module(components_dict, ["comp_id_1", "comp_id_2"])

# Validate mermaid diagrams in a generated markdown file
result = await validate_mermaid_diagrams(
    md_file_path="docs/architecture.md",
    relative_path="docs/architecture.md"
)
print(result)
```

## Notes

- Mermaid validation attempts `mermaid_parser` first, falling back to `mermaid-py` if unavailable; diagram errors include a numbered source window to help pinpoint the exact failing line in the original markdown file.
- The tiktoken encoder is initialized once at module load time (`gpt-4` model) for efficiency across repeated calls.
