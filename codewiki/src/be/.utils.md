Utility functions for token counting, Mermaid diagram validation/extraction, and module complexity analysis used throughout the CodeWiki documentation pipeline.

## Key Components

| Function | Description |
|---|---|
| `is_complex_module()` | Checks if a set of component IDs spans multiple files, indicating a complex module |
| `count_tokens()` | Counts GPT-4 tokens in a string using `tiktoken` |
| `validate_mermaid_diagrams()` | Async function that validates all Mermaid blocks in a markdown file and returns error details |
| `extract_mermaid_blocks()` | Parses markdown content and returns a list of `(line_number, diagram_content)` tuples |
| `validate_single_diagram()` | Validates one Mermaid block using `mermaid-parser-py` (falls back to `mermaid-py`) |
| `extract_and_save_mermaid_diagrams()` | Extracts all Mermaid blocks from a `.md` file and saves them as individual `.mmd` files |
| `create_diagrams_readme()` | Generates a `README.md` index for a directory of extracted `.mmd` diagram files |

## Usage Example

```python
import asyncio
from utils import (
    count_tokens,
    validate_mermaid_diagrams,
    extract_and_save_mermaid_diagrams,
    create_diagrams_readme,
)

# Count tokens before sending to LLM
token_count = count_tokens("Some prompt text here")
print(f"Tokens: {token_count}")

# Validate Mermaid diagrams in a generated doc
result = asyncio.run(
    validate_mermaid_diagrams(
        md_file_path="output/docs/my_module.md",
        relative_path="docs/my_module.md",
    )
)
print(result)
# "All mermaid diagrams in file: docs/my_module.md are syntax correct"
# or detailed error with line numbers

# Extract diagrams to individual .mmd files
diagram_files = extract_and_save_mermaid_diagrams(
    md_file_path="output/docs/my_module.md",
    diagrams_dir="output/diagrams",
)

# Generate a README index for the extracted diagrams
readme_path = create_diagrams_readme("output/diagrams", diagram_files)
```

## Notes

- Mermaid validation uses `mermaid-parser-py` as the primary engine and falls back to `mermaid-py` if unavailable or if a parse exception occurs outside the expected error pattern.
- Token counting uses the `gpt-4` encoding via `tiktoken` and applies globally to the module via a shared `enc` instance.
- Source: [`utils.py`](https://github.com/flamingo-stack/CodeWiki/blob/main/utils.py)
