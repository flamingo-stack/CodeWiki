Entry point module that enables running CodeWiki directly as a Python module via `python -m codewiki`, delegating execution to the CLI application.

## Key Components

- **`cli`** — Imported from `codewiki.cli.main`, this is the root Click command group that powers the CodeWiki command-line interface.

## Usage Example

```python
# Run from the command line as a module
# python -m codewiki

# Equivalent to invoking the CLI directly
from codewiki.cli.main import cli
cli()
```

```bash
# Standard module invocation
python -m codewiki --help

# Generate documentation for a repository
python -m codewiki generate --repo ./my-project
```

## Notes

- The `if __name__ == "__main__"` guard ensures `cli()` is only called when the module is executed directly, not when imported.
- For typical usage, prefer the installed `codewiki` CLI command over `python -m codewiki`.
- See the full CLI reference or contribute at [https://github.com/flamingo-stack/CodeWiki](https://github.com/flamingo-stack/CodeWiki).
