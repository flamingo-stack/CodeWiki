Entry point script that bootstraps the CodeWiki web application by configuring the Python path and delegating execution to the `fe.web_app.main` function.

## Key Components

| Component | Description |
|---|---|
| `src_dir` injection | Prepends the `src/` directory to `sys.path`, making all source modules importable |
| `fe.web_app.main` | Imported and invoked as the primary application entry point |

## Usage Example

```bash
# Run directly from the repository root
python run_web_app.py

# Or as an executable (Unix)
chmod +x run_web_app.py
./run_web_app.py
```

> **Note:** This script must be executed from the repository root so the relative `src/` path resolves correctly.
