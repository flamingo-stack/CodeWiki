Manages git operations for the CodeWiki CLI, including repository status checks, branch creation, documentation commits, and remote URL detection.

## Key Components

### `GitManager`
Main class that wraps [GitPython](https://gitpython.readthedocs.io/) to provide documentation-focused git workflows.

| Method | Description |
|---|---|
| `__init__(repo_path)` | Initializes the manager; raises `RepositoryError` if path is not a valid git repo |
| `check_clean_working_directory()` | Returns `(is_clean, status_message)` tuple with details on modified/untracked files |
| `create_documentation_branch(force)` | Creates a timestamped `docs/codewiki-YYYYMMDD-HHMMSS` branch and checks it out |
| `commit_documentation(docs_path, message)` | Stages and commits the docs directory; returns the commit SHA |
| `get_remote_url(remote_name)` | Returns the remote URL for the given remote name, or `None` |
| `get_current_branch()` | Returns active branch name, or `"HEAD"` in detached HEAD state |
| `get_commit_hash()` | Returns the current `HEAD` commit SHA |
| `branch_exists(branch_name)` | Checks whether a local branch exists by name |
| `get_github_pr_url(branch_name)` | Constructs a GitHub PR comparison URL, converting SSH remotes to HTTPS |

## Usage Example

```python
from pathlib import Path
from codewiki.cli.git_manager import GitManager
from codewiki.cli.utils.errors import RepositoryError

# Initialize against your repo root
manager = GitManager(Path("/path/to/your/repo"))

# Verify the working tree is clean before branching
is_clean, status = manager.check_clean_working_directory()
if not is_clean:
    print(f"Uncommitted changes:\n{status}")

# Create a timestamped docs branch
branch = manager.create_documentation_branch()  # e.g. "docs/codewiki-20240315-143022"

# Commit generated docs
docs_path = Path("/path/to/your/repo/docs")
sha = manager.commit_documentation(docs_path, message="docs: generated by CodeWiki")
print(f"Committed: {sha}")

# Get PR URL if hosted on GitHub
pr_url = manager.get_github_pr_url(branch)
if pr_url:
    print(f"Open PR at: {pr_url}")
```

> **Note:** `create_documentation_branch()` will raise `RepositoryError` if there are uncommitted changes unless `force=True` is passed.
