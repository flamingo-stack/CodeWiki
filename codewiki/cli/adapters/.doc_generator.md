# doc_generator.py

CLI adapter that wraps the backend `DocumentationGenerator` to add CLI-specific features such as progress reporting, colored logging, configuration display, and structured error handling for the `codewiki` command-line tool.

## Key Components

- **`CLIDocumentationGenerator`** — Main adapter class orchestrating documentation generation from the CLI.
  - `__init__(repo_path, output_dir, config, verbose=False, generate_html=False, diagrams_dir=None)` — Initializes job metadata, `ProgressTracker`, and `DocumentationJob`; configures backend logging.
  - `_configure_backend_logging()` — Sets up `logging.getLogger('codewiki.src.be')` with a `ColoredFormatter`; verbose mode logs `INFO`+ to stdout, non-verbose suppresses to `WARNING`+ on stderr. Disables propagation to avoid duplicate log lines.
  - `generate()` — Main entry point. Builds a `BackendConfig` from CLI options (per-provider models, API keys, base URLs, token limits, temperature settings, clustering parameters, additional source paths), runs backend generation via `asyncio.run`, optionally triggers HTML generation, finalizes the job, and returns the completed `DocumentationJob`. Raises `APIError` on LLM failures.
  - `_run_backend_generation(backend_config)` — Async method driving the multi-stage backend pipeline (dependency analysis, clustering, doc generation) with `ProgressTracker` updates per stage.

## Usage Example

```python
from pathlib import Path
from codewiki.cli.doc_generator import CLIDocumentationGenerator

config = {
    "main_model": "gpt-4o",
    "cluster_model": "gpt-4o-mini",
    "main_base_url": "https://api.openai.com/v1",
    "main_api_key": "sk-...",
    "cluster_api_key": "sk-...",
    "max_depth": 2,
    "additional_paths": ["shared/lib"],
}

generator = CLIDocumentationGenerator(
    repo_path=Path("./my-repo"),
    output_dir=Path("./docs-output"),
    config=config,
    verbose=True,
    generate_html=True,
)

job = generator.generate()
print(job.status, job.output_directory)
```

## Notes

- Requires `set_cli_context(True)` from `codewiki.src.config` to signal CLI mode to the backend.
- Additional source paths supplied in `config['additional_paths']` are resolved to absolute paths relative to `repo_path` before being passed to `BackendConfig`.
- Verbose mode prints a detailed configuration summary (models, base URLs, token limits, clustering settings) prior to generation.
