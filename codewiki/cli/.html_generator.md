Generates a self-contained `index.html` documentation viewer for GitHub Pages, embedding module tree data, metadata, and configuration as JSON into an HTML template for client-side markdown rendering.

## Key Components

### `HTMLGenerator`

Main class responsible for producing the static HTML viewer.

| Method | Description |
|---|---|
| `__init__(template_dir)` | Initializes the generator; defaults to the package's bundled `github_pages` template directory |
| `generate(...)` | Core method — loads template, injects config/module tree/metadata as JSON, writes `index.html` |
| `load_module_tree(docs_dir)` | Reads `module_tree.json` from the docs directory; falls back to a minimal structure if missing |
| `load_metadata(docs_dir)` | Reads `metadata.json` from the docs directory; returns `None` if unavailable |
| `detect_repository_info(repo_path)` | Introspects the local git repo to extract name, remote URL, and derived GitHub Pages URL |
| `_build_info_content(metadata)` | Builds an HTML snippet showing model, generation date, commit, and stats from metadata |
| `_escape_html(text)` | Sanitizes text before embedding in HTML attributes or content |

## Usage Example

```python
from pathlib import Path
from codewiki.cli.generators.html_generator import HTMLGenerator

generator = HTMLGenerator()

# Auto-detect repo info
repo_info = generator.detect_repository_info(Path("/path/to/repo"))

# Generate the viewer
generator.generate(
    output_path=Path("/path/to/repo/docs/index.html"),
    title="My Project Docs",
    docs_dir=Path("/path/to/repo/docs"),
    repository_url=repo_info["url"],
    github_pages_url=repo_info["github_pages_url"],
)
```

The generator reads `viewer_template.html` from the package templates and replaces placeholders such as `{{TITLE}}`, `{{MODULE_TREE_JSON}}`, and `{{CONFIG_JSON}}` before writing the final file. If `docs_dir` is provided, `module_tree.json` and `metadata.json` are loaded automatically.

## Notes

- Raises `FileSystemError` if the HTML template or module tree JSON cannot be read.
- Git SSH remote URLs (`git@github.com:owner/repo.git`) are normalized to HTTPS automatically.
- Requires the optional `gitpython` package for `detect_repository_info`.
