Defines the persistent configuration data models for the CodeWiki CLI, representing user settings stored in `~/.codewiki/config.json` and controlling LLM provider selection, token limits, and documentation agent behavior.

## Key Components

### `AgentInstructions`
A dataclass for customizing the documentation agent's behavior:

| Field | Type | Description |
|---|---|---|
| `include_patterns` | `Optional[List[str]]` | File glob patterns to include (e.g., `["*.py"]`) |
| `exclude_patterns` | `Optional[List[str]]` | File/dir patterns to exclude (e.g., `["*Tests*"]`) |
| `focus_modules` | `Optional[List[str]]` | Modules to document in greater detail |
| `doc_type` | `Optional[str]` | Documentation style: `api`, `architecture`, `user-guide`, `developer` |
| `custom_instructions` | `Optional[str]` | Free-form prompt additions |

Key methods: `to_dict()`, `from_dict()`, `is_empty()`, `get_prompt_addition()`

### `Configuration`
The primary settings dataclass persisted to disk. Manages three model roles — **cluster**, **main**, and **fallback** — each with independent API key, base URL, API version, token limit, temperature, and max-token field name settings. API keys are runtime-only (fetched from keyring, never written to disk).

Key fields and defaults:

| Field | Default |
|---|---|
| `default_output` | `"docs"` |
| `cluster_max_tokens` | `128000` |
| `main_max_tokens` | `128000` |
| `fallback_max_tokens` | `64000` |
| `max_token_per_module` | `36369` |
| `max_depth` | `2` |

Key methods: `validate()`, `to_dict()`, `from_dict()`

## Usage Example

```python
from codewiki.cli.models.config import Configuration, AgentInstructions

instructions = AgentInstructions(
    include_patterns=["*.py"],
    exclude_patterns=["*test*"],
    doc_type="api",
    custom_instructions="Include usage examples for every public function.",
)

config = Configuration(
    main_model="gpt-4o",
    cluster_model="gpt-4o-mini",
    fallback_model="gpt-3.5-turbo",
    default_output="wiki",
    agent_instructions=instructions,
)

config.validate()
serialized = config.to_dict()

restored = Configuration.from_dict(serialized)
print(restored.agent_instructions.get_prompt_addition())
```
