Data models for tracking documentation generation jobs, including status lifecycle, configuration, statistics, and JSON serialization.

## Key Components

- **`JobStatus`** — Enum with four states: `PENDING`, `RUNNING`, `COMPLETED`, `FAILED`
- **`GenerationOptions`** — Flags for branch creation, GitHub Pages, cache bypass, and custom output path
- **`JobStatistics`** — Counters for files analyzed, leaf nodes, tree depth, and token usage
- **`LLMConfig`** — Holds main model, cluster model, and base URL for the LLM backend
- **`DocumentationJob`** — Central dataclass representing a full job lifecycle with methods:
  - `start()` / `complete()` / `fail(error_message)` — state transitions with automatic timestamps
  - `to_dict()` / `to_json()` — serialization
  - `from_dict(data)` — deserialization (classmethod)

## Usage Example

```python
from job import DocumentationJob, GenerationOptions, LLMConfig, JobStatus

# Create a new job
job = DocumentationJob(
    repository_path="/repos/my-project",
    repository_name="my-project",
    output_directory="/docs/output",
    commit_hash="abc123",
    generation_options=GenerationOptions(create_branch=True, no_cache=True),
    llm_config=LLMConfig(
        main_model="gpt-4o",
        cluster_model="gpt-4o-mini",
        base_url="https://api.openai.com/v1"
    )
)

# Lifecycle transitions
job.start()
# ... do work ...
job.complete()

# Serialize / deserialize
json_str = job.to_json()
restored = DocumentationJob.from_dict(job.to_dict())
assert restored.status == JobStatus.COMPLETED

# Handle failure
job.fail("Repository not found")
print(job.error_message)  # "Repository not found"
```
