# job.py

Defines data models for representing documentation generation jobs, including their status, configuration, and statistics. Provides serialization/deserialization support for persisting job state as JSON.

## Key Components

- **`JobStatus`** — Enum representing job lifecycle states: `PENDING`, `RUNNING`, `COMPLETED`, `FAILED`.
- **`GenerationOptions`** — Dataclass holding generation flags (`create_branch`, `github_pages`, `no_cache`, `custom_output`).
- **`JobStatistics`** — Dataclass tracking metrics like `total_files_analyzed`, `leaf_nodes`, `max_depth`, and `total_tokens_used`.
- **`LLMConfig`** — Dataclass storing LLM settings: `main_model`, `cluster_model`, `base_url`.
- **`DocumentationJob`** — Main dataclass representing a full documentation job, including identifiers, timestamps, status, generated files, and nested config/stats objects. Provides:
  - `start()` — marks the job as `RUNNING` and updates start timestamp.
  - `complete()` — marks the job as `COMPLETED` and sets end timestamp.
  - `fail(error_message)` — marks the job as `FAILED` with an error message.
  - `to_dict()` / `to_json()` — serialize the job to a dictionary or JSON string.
  - `from_dict(data)` — class method to reconstruct a `DocumentationJob` from a dictionary, safely coercing nested fields.
- **Helper coercion functions** (`_coerce_job_status`, `_coerce_int`, `_coerce_generation_options`, `_coerce_llm_config`, `_coerce_statistics`) — internally used to safely convert raw dict/JSON values into typed dataclass instances, tolerating missing or malformed data.

## Usage Example

```python
from job import DocumentationJob, GenerationOptions, LLMConfig

# Create a new job
job = DocumentationJob(
    repository_path="/repos/my-project",
    repository_name="my-project",
    output_directory="/output/my-project",
    commit_hash="abc123",
    generation_options=GenerationOptions(create_branch=True, github_pages=True),
    llm_config=LLMConfig(main_model="gpt-4", cluster_model="gpt-4-mini", base_url="https://api.openai.com"),
)

job.start()
# ... perform documentation generation ...
job.module_count = 12
job.complete()

# Serialize to JSON for storage
json_str = job.to_json()

# Reload from persisted data
restored_job = DocumentationJob.from_dict(job.to_dict())
print(restored_job.status)  # JobStatus.COMPLETED
```
