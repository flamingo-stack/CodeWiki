Generates and displays post-generation instructions and summaries for CodeWiki's documentation pipeline, including Git workflow guidance, GitHub Pages setup steps, and generation statistics.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `compute_github_pages_url` | Function | Derives the expected GitHub Pages URL from a repository URL and name |
| `get_pr_creation_url` | Function | Builds a GitHub compare/PR creation URL for a given branch |
| `display_post_generation_instructions` | Function | Renders a full post-generation report: output path, file list, statistics, and next-step Git/GitHub Pages instructions |
| `display_generation_summary` | Function | Prints a concise success or failure summary after a generation run |

## Usage Example

```python
from pathlib import Path
from instructions import (
    display_post_generation_instructions,
    display_generation_summary,
    compute_github_pages_url,
)

# Show full post-generation instructions
display_post_generation_instructions(
    output_dir=Path("docs"),
    repo_name="CodeWiki",
    repo_url="https://github.com/flamingo-stack/CodeWiki",
    branch_name="docs/auto-generated",
    github_pages=True,
    files_generated=["overview.md", "api.md", "index.html"],
    statistics={
        "module_count": 12,
        "total_files_analyzed": 48,
        "generation_time": 125.4,
    },
)

# Compute GitHub Pages URL independently
url = compute_github_pages_url(
    "https://github.com/flamingo-stack/CodeWiki",
    "CodeWiki"
)
# -> "https://flamingo-stack.github.io/CodeWiki/"

# Show a simple success/failure summary
display_generation_summary(success=True, output_dir=Path("docs"))
display_generation_summary(success=False, error_message="API quota exceeded")
```
