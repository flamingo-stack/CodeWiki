Validation utilities for CLI inputs and configuration, providing sanitization and format-checking functions for URLs, API keys, model names, file paths, and repository directories.

## Key Components

| Function | Description |
|---|---|
| `validate_url()` | Validates URL format, scheme presence, and optional HTTPS enforcement (with localhost exemption) |
| `validate_api_key()` | Checks API key is non-empty and meets minimum length requirements |
| `validate_model_name()` | Ensures model name is a non-empty string |
| `validate_output_directory()` | Resolves and validates a writable output directory path |
| `validate_repository_path()` | Confirms a repository path exists and is a directory |
| `detect_supported_languages()` | Scans a directory and returns detected languages with file counts, excluding common build/cache dirs |
| `is_top_tier_model()` | Returns `True` if the model name matches a known high-capability model (e.g., `gpt-4`, `claude-opus`) |
| `mask_api_key()` | Masks an API key for safe display, showing only the first and last few characters |

## Usage Example

```python
from pathlib import Path
from codewiki.cli.utils.validation import (
    validate_url,
    validate_api_key,
    validate_repository_path,
    detect_supported_languages,
    mask_api_key,
)

# Validate a server URL (HTTPS required, localhost exempt)
server = validate_url("http://localhost:8080", require_https=True)

# Validate an API key
key = validate_api_key("sk-abcdef1234567890")
print(mask_api_key(key))  # "sk-a...7890"

# Validate and scan a local repository
repo = validate_repository_path(Path("~/projects/my-app"))
languages = detect_supported_languages(repo)
# [('TypeScript', 142), ('Python', 38), ('JavaScript', 12)]
```

## Error Handling

- URL, API key, model, and directory validators raise `ConfigurationError` on invalid input.
- `validate_repository_path()` raises `RepositoryError` if the path is missing or not a directory.
- Both error types are imported from [`codewiki.cli.utils.errors`](https://github.com/flamingo-stack/CodeWiki/blob/main/codewiki/cli/utils/errors.py).
