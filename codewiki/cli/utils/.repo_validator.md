Provides repository validation utilities for documentation generation, including path validation, output directory writability checks, and Git metadata retrieval.

## Key Components

| Name | Type | Description |
|------|------|-------------|
| `SUPPORTED_EXTENSIONS` | `set` | File extensions for supported languages (Python, Java, JS/TS, C/C++, C#, PHP) |
| `validate_repository()` | `function` | Validates a repo path exists, contains supported files, and returns detected languages |
| `check_writable_output()` | `function` | Verifies an output directory exists and is writable (or its parent allows creation) |
| `is_git_repository()` | `function` | Checks whether a given path contains a `.git` directory |
| `get_git_commit_hash()` | `function` | Returns the current HEAD commit SHA using `gitpython` |
| `get_git_branch()` | `function` | Returns the active branch name using `gitpython` |
| `count_code_files()` | `function` | Counts all supported source files recursively within a repo |

## Usage Example

```python
from pathlib import Path
from codewiki.cli.utils.repo_validator import (
    validate_repository,
    check_writable_output,
    is_git_repository,
    get_git_commit_hash,
    get_git_branch,
    count_code_files,
)

repo = Path("/path/to/my/project")

# Validate the repo has supported source files
validated_path, languages = validate_repository(repo)
print(languages)  # e.g. [('Python', 42), ('TypeScript', 17)]

# Ensure docs output directory is writable
output = check_writable_output(Path("./docs"))

# Git metadata
if is_git_repository(repo):
    print(get_git_branch(repo))       # e.g. "main"
    print(get_git_commit_hash(repo))  # e.g. "a1b2c3d4..."

# Count source files
total = count_code_files(repo)
print(f"Found {total} code files")
```

Both `validate_repository()` and `check_writable_output()` raise `RepositoryError` on failure, making them safe to use directly in CLI entry points without additional try/except handling.
