Progress indicator utilities for CLI-based documentation generation workflows, providing stage-based tracking with ETA estimation and per-module progress bars.

## Key Components

### `ProgressTracker`
Multi-stage progress tracker with weighted time estimation across five predefined pipeline stages:

| Stage | Name | Weight |
|---|---|---|
| 1 | Dependency Analysis | 40% |
| 2 | Module Clustering | 20% |
| 3 | Documentation Generation | 30% |
| 4 | HTML Generation | 5% |
| 5 | Finalization | 5% |

**Key methods:**
- `start_stage(stage, description)` — begins a numbered stage with optional label override
- `update_stage(progress, message)` — updates intra-stage progress (`0.0`–`1.0`)
- `complete_stage(message)` — marks stage done, logs elapsed stage time in verbose mode
- `get_overall_progress()` — returns weighted overall progress (`0.0`–`1.0`)
- `get_eta()` — returns human-readable remaining time estimate (e.g., `"2m 30s"`, `"1h 5m"`)

### `ModuleProgressBar`
Wraps `click.progressbar` for per-module documentation generation with cache-aware status display.

**Key methods:**
- `update(module_name, cached)` — advances bar, labels cached vs. freshly generated modules
- `finish()` — cleanly exits the progress bar context manager

## Usage Example

```python
from progress import ProgressTracker, ModuleProgressBar

tracker = ProgressTracker(total_stages=5, verbose=True)

tracker.start_stage(1)
tracker.update_stage(0.5, "Scanning imports...")
tracker.complete_stage("Found 42 dependencies")

eta = tracker.get_eta()  # e.g., "1m 20s"
overall = tracker.get_overall_progress()  # e.g., 0.40

modules = ["auth", "db", "api"]
bar = ModuleProgressBar(total_modules=len(modules), verbose=False)
for mod in modules:
    bar.update(mod, cached=False)
bar.finish()
```

## Notes

- Verbose mode (`verbose=True`) prefixes all output with a `MM:SS` elapsed timestamp via `_format_elapsed()`
- ETA returns `None` until measurable progress has been recorded
- `ModuleProgressBar` uses `click.progressbar` as a context manager internally; always call `finish()` to avoid broken terminal output
