# api_errors.py

Provides fail-fast error handling for LLM API calls within the CodeWiki CLI, converting raw exceptions into user-friendly `APIError` instances with contextual troubleshooting guidance based on the detected error type (rate limits, auth failures, timeouts, network issues).

## Key Components

- **`APIErrorHandler`** — Static utility class for API error handling:
  - `handle_api_error(error, context=None, fail_fast=True)`: Inspects the exception message for known patterns (`429`/rate limit, `401`/authentication, timeout, network/connection) and builds a detailed `APIError` with troubleshooting steps specific to the failure type. Falls back to a generic message for unrecognized errors. Always returns an `APIError`; does not raise it.
  - `display_api_error(error, module_name=None)`: Pretty-prints an `APIError` to the terminal using `click`, including optional module context and a warning that no partial results were saved.

- **`wrap_api_call(func, *args, fail_fast=True, context=None, **kwargs)`** — Convenience wrapper that invokes `func`, catches any exception, converts it via `APIErrorHandler.handle_api_error`, and either raises the resulting `APIError` (if `fail_fast=True`) or displays it and returns `None` (if `fail_fast=False`).

## Usage Example

```python
from codewiki.cli.utils.api_errors import wrap_api_call, APIErrorHandler

def call_llm(prompt: str):
    # Some function that may raise on 429, 401, timeout, etc.
    return llm_client.generate(prompt)

# Fail-fast: raises APIError immediately on failure
result = wrap_api_call(call_llm, "Summarize this module", context="docs_generator")

# Non-fail-fast: logs a formatted error and returns None instead of raising
result = wrap_api_call(
    call_llm,
    "Summarize this module",
    fail_fast=False,
    context="docs_generator",
)

# Manual handling
try:
    call_llm("...")
except Exception as e:
    api_error = APIErrorHandler.handle_api_error(e, context="my_module")
    APIErrorHandler.display_api_error(api_error, module_name="my_module")
    raise api_error
```
