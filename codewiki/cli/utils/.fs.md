File system utility functions for CLI operations, providing safe and atomic file I/O, directory management, and file discovery with consistent error handling via `FileSystemError`.

## Key Components

| Function | Description |
|---|---|
| `ensure_directory(path, mode)` | Creates a directory (and parents) if it doesn't exist; defaults to `0o700` permissions |
| `check_writable(path)` | Returns `True` if the path (or its parent) is writable |
| `safe_write(path, content, encoding)` | Atomically writes content via a temp file + rename to prevent partial writes |
| `safe_read(path, encoding)` | Reads file content with descriptive error wrapping |
| `get_file_size(path)` | Returns file size in bytes |
| `find_files(directory, extensions, recursive)` | Globs files by extension, optionally recursive |
| `cleanup_directory(path, keep_hidden)` | Removes directory contents, optionally preserving hidden files |

## Usage Example

```python
from pathlib import Path
from codewiki.cli.utils.fs import (
    ensure_directory, safe_write, safe_read,
    find_files, cleanup_directory
)

# Create a config directory with restricted permissions
config_dir = ensure_directory(Path("~/.codewiki/config"))

# Atomically write a config file
safe_write(config_dir / "settings.json", '{"theme": "dark"}')

# Read it back
content = safe_read(config_dir / "settings.json")

# Find all Python files in a project
py_files = find_files(Path("./src"), extensions=[".py", ".pyi"])

# Clean up a temp directory, keeping dotfiles
cleanup_directory(Path("~/.codewiki/tmp"), keep_hidden=True)
```

> All functions raise `FileSystemError` (from `codewiki.cli.utils.errors`) on failure, providing actionable messages such as suggested `chmod` commands for permission issues.
