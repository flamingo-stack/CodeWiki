Defines CLI error handling utilities, custom exception hierarchy, exit codes, and user-facing message helpers for the CodeWiki command-line interface.

## Key Components

### Exit Code Constants

| Constant | Code | Meaning |
|---|---|---|
| `EXIT_SUCCESS` | 0 | Operation completed successfully |
| `EXIT_GENERAL_ERROR` | 1 | Unclassified error |
| `EXIT_CONFIG_ERROR` | 2 | Missing or invalid credentials/config |
| `EXIT_REPOSITORY_ERROR` | 3 | Not a git repo or no code files found |
| `EXIT_API_ERROR` | 4 | LLM API failure or rate limit |
| `EXIT_FILESYSTEM_ERROR` | 5 | Permission or disk space issues |

### Exception Classes

- **`CodeWikiError`** — Base exception; accepts `message` and `exit_code`
- **`ConfigurationError`** — Raised for credential/config issues (exit 2)
- **`RepositoryError`** — Raised for git/repo problems (exit 3)
- **`APIError`** — Raised for LLM API failures (exit 4)
- **`FileSystemError`** — Raised for I/O problems (exit 5)

### Functions

- **`handle_error(error, verbose)`** — Catches `CodeWikiError` subclasses and unknown exceptions; returns the appropriate exit code; prints stack trace when `verbose=True`
- **`error_with_suggestion(message, suggestion, exit_code)`** — Prints a red error followed by an actionable hint, then calls `sys.exit()`
- **`warning(message)`** — Prints a yellow `⚠️` prefixed message
- **`success(message)`** — Prints a green `✓` prefixed message
- **`info(message)`** — Prints a plain info message

## Usage Example

```python
from errors import (
    ConfigurationError,
    APIError,
    handle_error,
    error_with_suggestion,
    warning,
    success,
)

# Raise a typed error and handle it
try:
    raise ConfigurationError("OPENAI_API_KEY is not set")
except Exception as e:
    exit_code = handle_error(e, verbose=True)
    sys.exit(exit_code)

# Exit immediately with a suggestion
error_with_suggestion(
    message="No git repository found",
    suggestion="Run `git init` in your project root first.",
    exit_code=EXIT_REPOSITORY_ERROR,
)

# User-facing status messages
warning("Rate limit approaching — slowing requests")
success("Documentation generated successfully")
```
