Colored CLI logging utility that provides timestamped, level-aware output with progress tracking for command-line interfaces using Click.

## Key Components

### `CLILogger`
Main logger class with support for verbose and normal output modes.

| Method | Output Color | Description |
|--------|-------------|-------------|
| `debug(message)` | Cyan (dim) | Timestamped output, verbose mode only |
| `info(message)` | Default | Plain echo |
| `success(message)` | Green | Prefixed with `✓` |
| `warning(message)` | Yellow | Prefixed with `⚠️` |
| `error(message)` | Red | Writes to `stderr` |
| `step(message, step, total)` | Blue (bold) | Step progress, e.g. `[1/5]` or `→` |
| `elapsed_time()` | — | Returns time since logger init as `"Xm Ys"` |

### `create_logger(verbose)`
Factory function that instantiates and returns a `CLILogger`.

## Usage Example

```python
from logging import create_logger

logger = create_logger(verbose=True)

logger.step("Fetching repositories", step=1, total=3)
logger.debug("Connecting to GitHub API...")   # only shown in verbose mode
logger.info("Processing files...")
logger.success("All files synced")
logger.warning("Rate limit approaching")
logger.error("Failed to connect")

print(f"Completed in {logger.elapsed_time()}")
# Output: "Completed in 4s"
```
