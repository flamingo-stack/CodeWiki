# logging.py

Provides colored, human-friendly CLI logging utilities built on top of `click.secho`, including verbose/debug support, elapsed-time tracking, and suppression of noisy third-party HTTP/SDK loggers (`httpx`, `openai`, `anthropic`) during CLI runs.

## Key Components

- **`CLILogger`** — Main logging class for CLI output:
  - `debug(message)` — Cyan, timestamped output shown only when `verbose=True`.
  - `info(message)` — Plain output via `click.echo`.
  - `success(message)` — Green output prefixed with `✓`.
  - `warning(message)` — Yellow output prefixed with `⚠️`.
  - `error(message)` — Red output prefixed with `✗`, written to stderr.
  - `step(message, step, total)` — Bold blue step indicator, optionally showing `[step/total]` progress.
  - `elapsed_time()` — Returns a formatted string (e.g. `"2m 5s"`) of time since the logger was created.
- **`quiet_third_party_loggers(level=logging.WARNING)`** — Sets the log level for known noisy libraries (`httpx`, `openai`, `openai._base_client`, `anthropic`) to reduce CI/log clutter.
- **`create_logger(verbose=False)`** — Factory function that quiets third-party loggers and returns a configured `CLILogger` instance. This is the recommended entry point.

## Usage Example

```python
from logging import create_logger

# Create a logger (suppresses noisy HTTP/SDK logs automatically)
logger = create_logger(verbose=True)

logger.step("Fetching repository data", step=1, total=3)
logger.debug("Connecting to GitHub API...")
logger.success("Repository cloned successfully")
logger.warning("Rate limit approaching")
logger.error("Failed to parse config file")

logger.info(f"Done in {logger.elapsed_time()}")
```

**Note:** Always use `create_logger()` rather than instantiating `CLILogger` directly, since it ensures third-party logging noise is suppressed at the point of use rather than as an import-time side effect.
