Handles CLI configuration management for CodeWiki, providing commands to set, view, and validate per-provider LLM configuration options (cluster, main, and fallback models) while managing backward compatibility with deprecated single-provider options.

## Key Components

- **`parse_patterns(patterns_str)`** — Splits a comma-separated string into a cleaned list of pattern strings
- **`parse_bool_string(ctx, param, value)`** — Click callback that normalizes boolean-like strings (`"true"`, `"1"`, `"yes"`) to Python `bool`
- **`_validate_no_deprecated_options(ctx, param, value)`** — Click callback that intercepts removed CLI flags (e.g., `--base-url`, `--max-tokens`) and raises a `UsageError` with a migration guide
- **`config_group`** — Top-level `@click.group` named `config` that groups all configuration subcommands
- **`config_set`** — Primary subcommand (`config set`) exposing ~27 options for per-provider LLM settings (API keys, base URLs, models, token limits, temperatures, API versions)

## Usage Example

```bash
# Set per-provider configuration
codewiki config set \
  --cluster-api-key sk-abc123 \
  --main-api-key sk-abc123 \
  --cluster-base-url https://api.anthropic.com/v1 \
  --main-base-url https://api.anthropic.com/v1 \
  --cluster-model claude-sonnet-4 \
  --main-model claude-sonnet-4 \
  --cluster-max-tokens 128000 \
  --main-max-tokens 128000

# Update only the fallback model token limit
codewiki config set --fallback-max-tokens 64000

# Attempting a deprecated flag raises a migration error
codewiki config set --base-url https://api.openai.com/v1
# ERROR: '--base-url' is DEPRECATED → use --cluster-base-url, --main-base-url, --fallback-base-url
```

> **Migration note:** Single-provider flags (`--base-url`, `--max-tokens`, `--api-version`, `--max-token-field`, `--api-path`) were removed. Replace them with their per-provider equivalents (`--cluster-*`, `--main-*`, `--fallback-*`). See the [migration guide](https://github.com/flamingo-stack/CodeWiki#migration).
