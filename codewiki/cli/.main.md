Entry point for the CodeWiki CLI application, built with the Click framework. Defines the root command group, registers subcommands, and handles top-level error management.

## Key Components

| Component | Description |
|---|---|
| `cli` | Root Click command group with version option support |
| `version` | Subcommand that prints version and runtime info |
| `main()` | Entry point function; handles `KeyboardInterrupt` and unexpected exceptions with clean exit codes |
| `config_group` | Imported and registered config subcommand group |
| `generate_command` | Imported and registered `generate` subcommand |

## Usage Example

```bash
# Show help
codewiki --help

# Show version via flag
codewiki --version

# Show version via subcommand
codewiki version

# Run generate command
codewiki generate

# Manage configuration
codewiki config
```

```python
# Invoke programmatically (e.g., in tests)
from click.testing import CliRunner
from main import cli

runner = CliRunner()
result = runner.invoke(cli, ["--version"])
print(result.output)  # CodeWiki CLI v<version>
```

## Error Handling

| Signal / Exception | Exit Code | Behavior |
|---|---|---|
| `KeyboardInterrupt` | `130` | Prints "Interrupted by user" to stderr |
| Any other `Exception` | `1` | Prints error message in red to stderr |
