Package entry point for **CodeWiki**, an AI-powered documentation generator that transforms codebases into comprehensive documentation. Exposes the CLI interface and package metadata.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `cli` | Click group | Main CLI entry point imported from `codewiki.cli.main` |
| `__version__` | `str` | Current package version (`1.0.1`) |
| `__author__` | `str` | Package author attribution |
| `__license__` | `str` | MIT license identifier |

## Usage Example

**Programmatic access to the CLI:**

```python
from codewiki import cli, __version__

# Check installed version
print(__version__)  # "1.0.1"

# Invoke CLI programmatically (e.g., in tests)
from click.testing import CliRunner

runner = CliRunner()
result = runner.invoke(cli, ["--help"])
print(result.output)
```

**Standard CLI usage (after install):**

```bash
# Run via entry point
codewiki --help

# Check version
codewiki --version
```

## Notes

- The `cli` object is the sole public interface; all command logic lives under [`codewiki/cli/main.py`](https://github.com/flamingo-stack/CodeWiki/blob/main/codewiki/cli/main.py)
- `__all__` restricts `from codewiki import *` to `cli` and `__version__` only
- Install via:

```bash
git clone https://github.com/flamingo-stack/CodeWiki.git
cd CodeWiki && pip install -e .
```
