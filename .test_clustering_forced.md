# test_clustering_forced.py

An integration test script that forces the LLM-based module clustering logic to actually invoke an LLM call by setting an artificially low `max_token_per_module` threshold, verifying the LLM correctly returns results using the expected `<GROUPED_COMPONENTS>` tag format.

## Key Components

- **`TestResults`** — Lightweight test result tracker that collects `(name, passed, message)` tuples and prints a pass/fail summary via `print_summary()`.
- **`config`** — A `Config` instance configured with a very low `max_token_per_module=50` to force `cluster_modules` to trigger an actual LLM clustering call rather than using a trivial/no-op path.
- **Synthetic components** — 10 fake `Node` objects (`Component0`...`Component9`) representing Java classes, used as input leaf nodes for clustering.
- **Main script flow** — Calls `cluster_modules` with the synthetic components and asserts that a non-empty `module_tree` is returned, indicating the LLM correctly parsed and grouped components.

## Usage Example

Run directly as a script (requires a `.env.local` file with API credentials):

```bash
# Optional overrides via environment variables
export TEST_REPO_PATH=/path/to/repo
export MAIN_MODEL=gpt-4o
export CLUSTER_MODEL=gpt-4o
export OPENAI_API_KEY=sk-...
export ANTHROPIC_API_KEY=sk-ant-...

python test_clustering_forced.py
```

Expected successful output:

```text
🤖 Model: gpt-4o
📏 FORCED max tokens: 50 (will force LLM call)

📦 Components: 10

🔄 Running clustering (WILL call LLM)...
================================================================================
================================================================================

📊 RESULTS:

✅ SUCCESS: 3 modules created

Modules generated:
   - core_module: 4 components
   - utils_module: 3 components
   - service_module: 3 components

🎉 THE FIX WORKS! LLM followed the <GROUPED_COMPONENTS> tag format!

📊 TEST SUMMARY:

✅ PASS: clustering_produces_module_tree - 3 modules created
```

The script exits with code `0` on success and `1` if the module tree is empty (indicating the LLM failed to follow the expected tag format).
