Validation test script for ID-based clustering fixes, verifying four critical behaviors: safe JSON parsing, correct function return type handling, integer ID validation, and ID-to-FQDN normalization.

## Key Components

| Function | Description |
|---|---|
| `test_json_parsing()` | Verifies `json.loads()` correctly handles integer IDs and flags quoted string IDs |
| `test_return_types()` | Validates 4-tuple unpacking from `format_potential_core_components()` and catches the old `result[-1]` bug |
| `test_id_validation()` | Checks that component IDs are integers within valid range `[0, max_id]` |
| `test_normalization()` | Confirms integer IDs are correctly resolved to fully-qualified domain names (FQDNs) |

## Notes

- Replaces unsafe `eval()` with `json.loads()` to prevent arbitrary code execution during cluster parsing
- The return-type test mocks `format_potential_core_components()` to expose the original bug where `result[-1]` returned a `Dict` instead of a `str`, causing `TypeError` in downstream `count_tokens()` calls
