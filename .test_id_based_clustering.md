# test_id_based_clustering.py

Standalone validation script that verifies fixes made to the ID-based clustering logic used during code component grouping. It exercises four specific bug fixes without depending on the actual clustering module, using mocked/simulated data to demonstrate correct behavior.

## Key Components

- **`TestResults`** - Simple accumulator class that collects `(name, passed)` tuples and prints a pass/fail summary via `print_summary()`.
- **`test_json_parsing()`** - Confirms `json.loads()` (instead of the unsafe `eval()`) correctly parses integer component IDs, and demonstrates that quoted string IDs (e.g. `"0"`) parse but are semantically invalid.
- **`test_return_types()`** - Validates that `format_potential_core_components()` returns a 4-tuple and that correct unpacking (`_, code_str, _, _`) yields a string suitable for token counting, contrasting with the old buggy pattern of using `result[-1]` (a `Dict`).
- **`test_id_validation()`** - Checks logic for validating that component IDs are integers within a valid range `[0, max_id]`, testing both valid and invalid (string, out-of-range) ID sets.
- **`test_normalization()`** - Verifies that integer component IDs are correctly mapped to fully-qualified domain names (FQDNs) via an `id_to_fqdn` lookup dictionary, replacing raw IDs in a module tree structure.

## Usage Example

Run directly as a script; it requires no arguments and exits with a status code indicating overall success:

```bash
python test_id_based_clustering.py
```

Exit codes:
- `0` — all four tests passed
- `1` — one or more tests failed

Programmatic use of `TestResults`:

```python
from test_id_based_clustering import TestResults, test_json_parsing

results = TestResults()
results.add_test("JSON parsing", test_json_parsing())
all_passed = results.print_summary()
```

This script is intended for manual/CI verification of clustering-related bug fixes (safe JSON parsing, correct tuple unpacking, strict integer ID validation, and ID-to-FQDN normalization) rather than as an importable library.
